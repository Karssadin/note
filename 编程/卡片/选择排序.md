每次从未排序区间中找到**最小元素**，放到已排序区间的末尾。

- 时间复杂度：O(n²)，与数据初始状态无关
- 空间复杂度：O(1)
- **不稳定**：交换可能破坏相等元素的相对顺序（如 `[5a, 5b, 2]` → `[2, 5b, 5a]`）

```cpp
void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx])
                minIdx = j;
        }
        swap(arr[i], arr[minIdx]);
    }
}
```

与插入排序相比，选择排序的比较次数固定为 n(n-1)/2，但交换次数最多 n-1 次，在写入代价高的场景（如 Flash 存储）中有优势。
