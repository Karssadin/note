# 插入排序

插入排序维护一个有序前缀，每次把当前元素插入到前面已经有序的位置。

```cpp
for (int i = 1; i < n; ++i) {
    int x = a[i];
    int j = i - 1;
    while (j >= 0 && a[j] > x) {
        a[j + 1] = a[j];
        --j;
    }
    a[j + 1] = x;
}
```

## 特点

1. 平均和最坏时间复杂度为 O(n²)。
2. 数据基本有序时接近 O(n)。
3. 空间复杂度为 O(1)。
4. 稳定排序。
5. 常用于小数组，很多工业排序会在小区间切换到插入排序。
