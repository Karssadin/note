> 注意区分两个"堆栈"：**堆栈（数据结构）** 是后进先出的线性结构；**堆区与栈区** 是程序的内存存储区域，是两回事。

## 栈区（Stack）

- 由**编译器自动分配和释放**
- 存储：函数参数、局部变量、返回地址、函数调用上下文
- 分配方式：静态分配（编译期确定）或 `alloca()` 动态分配（仍由编译器回收）
- 大小：**固定**，Linux 默认约 8MB（`ulimit -s`），超出导致栈溢出
- 生长方向：**从高地址向低地址**
- 速度：**极快**（只需移动栈指针 RSP/ESP）
- 生命周期：随函数调用入栈，函数返回出栈，自动管理

## 堆区（Heap）

- 由**程序员手动分配和释放**（`new/delete`、`malloc/free`）
- 存储：动态分配的数据结构（对象、数组等）
- 分配方式：动态分配，类似链表管理
- 大小：**可动态增长**，受进程虚拟地址空间和物理内存限制
- 生长方向：**从低地址向高地址**
- 速度：**较慢**（需要搜索空闲块，可能触发 `brk()`/`mmap()` 系统调用）
- 生命周期：直到 `delete/free` 或程序退出（OS 回收）

## 对比表

| 维度 | 栈区 | 堆区 |
|------|------|------|
| 分配方式 | 编译器自动管理 | 程序员手动管理 |
| 分配速度 | 快（移动栈指针） | 慢（搜索空闲块） |
| 大小 | 固定，约 8MB | 可动态增长，更大 |
| 生长方向 | 高地址 → 低地址 | 低地址 → 高地址 |
| 内存碎片 | 不存在（后进先出） | 频繁分配/释放会产生碎片 |
| 线程 | 每个线程有独立的栈 | 同一进程的线程共享堆 |
| 典型数据 | 局部变量、函数参数 | `new` 的对象、STL 容器内部 |

## 何时用堆

- 数据生命周期超过函数调用期（跨函数存活）
- 需要分配的数据**较大**，超过栈容量
- 运行时才能确定需要分配的大小（动态数组等）

## 常见问题

```cpp
// 栈溢出：函数递归太深或局部变量太大
void foo() { int big[10000000]; }  // 10M 数组放栈上会溢出

// 堆碎片：频繁分配/释放小块内存
for (int i = 0; i < 10000; i++) {
    int* p = new int;
    delete p;  // 每次大小不同则会产生碎片
}

// 推荐：用 RAII/智能指针管理堆内存
auto ptr = std::make_unique<LargeObject>();
```
