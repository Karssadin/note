# 排序算法

- [[排序算法总结]]：全部排序算法对比表、稳定性、选择建议

### 比较排序

- [[冒泡排序]]：相邻交换，O(n²)，稳定
- [[选择排序]]：每次选最小，O(n²)，不稳定
- [[插入排序]]：逐个插入已排序区间，O(n²)，稳定
- [[希尔排序]]：分组插入排序，O(n^1.3)，不稳定
- [[快速排序]]：分治 + pivot 划分，平均 O(n log n)，不稳定
- [[归并排序]]：分治 + 合并，O(n log n)，稳定
- [[堆排序]]：利用大顶堆，O(n log n)，不稳定

### 非比较排序

- [[计数排序]]：计数 + 前缀和，O(n+k)，稳定
- [[桶排序与基数排序]]：分桶/按位排序，突破 O(n log n) 下界

# 搜索与遍历

- [[树的遍历总结]]：前序/中序/后序（递归 + 统一迭代法）、层序遍历
- [[图的遍历算法]]：DFS（栈）、BFS（队列）、图的存储方式
- [[最短路径算法]]：Dijkstra（非负权）、Bellman-Ford（含负权）、Floyd-Warshall（全源）
- [[最小生成树算法]]：Kruskal（边排序+并查集）、Prim（贪心+优先队列）、拓扑排序
- [[二分查找算法|二分查找]]：有序序列上的 O(log n) 查找

# 算法思想

- [[递归与分治]]：将问题分解为子问题递归求解，主定理分析复杂度
- [[动态规划思想]]：重叠子问题 + 最优子结构，记忆化/递推/空间优化
- [[贪心算法思想]]：每步局部最优，需证明贪心选择性质
- [[回溯算法思想]]：DFS + 剪枝，适用于排列/组合/子集/约束满足
