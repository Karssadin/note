# Go基础知识

Go 基础主要关注包、声明、函数、控制流和错误处理。Go 的设计倾向于简单语法、显式错误和组合式抽象。

1. 包与导入
	1. 每个文件属于一个 package
	2. 以大写字母开头的标识符可被包外访问
2. 声明
	1. `var` 声明变量
	2. `const` 声明常量
	3. `:=` 用于函数内部短变量声明
3. 控制结构
	1. `if` 支持初始化语句
	2. `for` 是唯一循环关键字
	3. `switch` 默认不贯穿
