类模板中使用友元函数需要特殊处理，因为模板的实例化时机与友元声明的可见性相关。

**核心规则**：如果友元函数在类外实现且是模板函数，需要在类定义前进行前向声明（类和函数都要声明），并在友元声明中添加 `<>` 参数列表。

```cpp
//提前让声明Person，不然全局函数的类外实现会找不到该class
template<typename T1,typename T2>
class Person;
//提前声明全局函数的类外实现，不然友元的话会报错
template<typename T1,typename T2>
void printPerson(Person<T1,T2> p);

template<typename T1,typename T2>
class Person{
	//全局函数，在类内实现
	void printPerson(Person<T1,T2> p){
		cout<<p.Name<<p.Age;
	}
	//普通函数的声明，无法使用，因为下面的实现是模板函数，错误
	//friend void  printPerson(Person<T1,T2> p);
	//添加参数列表,如果全局函数类外实现，需要让编译器知道该全局模板函数，需要声明一下
	friend void  printPerson<>(Person<T1,T2> p);

public:
	Person(NameType name,AgeType age){
		this->Name=name;
		this->Age=age;
	}
private:
	NameType Name;
	AgeType Age;
};
//全局函数类外实现，需要友元
template<typename T1,typename T2>
void printPerson(Person<T1,T2> p){
	cout<<p.Name<<p.Age;
}
```
