## 概述
- 在C11之前，函数/类模板参数数量必须固定，比如：
```
template <typename T1, typename T2, typename T3>
void foo(T1 a, T2 b, T3 c);
```

## 可变参数模板
1. 利用递归展开，写一个递归终止函数即可。
```C++
// C++11: 递归展开版
#include <iostream>

void print() { std::cout << '\n'; } // 递归终止

template<typename T, typename... Rest>
void print(T first, Rest... rest) {
    std::cout << first << " ";
    print(rest...);
}

int main() {
    print(1, 3.14, "hello", 'c'); // 输出: 1 3.14 hello c
}
```

## 完美转发+可变参数实现（工厂、容器接口）
```C++
#include <vector>
#include <utility> // for std::forward

// 1. 工厂函数：创建对象
template<typename T, typename... Args>
T* make(Args&&... args) {
    return new T(std::forward<Args>(args)...);
}

auto* p = make<std::string>(10, 'a');
// 等价于 new std::string(10, 'a');


// 2. 容器助手：往 vector 里原地构造元素
template<typename T, typename... Args>
void push_emplace(std::vector<T>& v, Args&&... args) {
    v.emplace_back(std::forward<Args>(args)...);
}

std::vector<std::pair<int, double>> v;
push_emplace(v, 1, 3.14);
// 等价于 v.emplace_back(std::pair<int,double>(1, 3.14));

```
 - `typename... Args`: 模板参数包，可以匹配任意数量的类型。
- `Args&&... args`:  函数参数包，接受任意数量的参数。
- `(expr)...`: 参数包展开，把参数逐个传给构造函数。
- 参数写成 `Args&&...`（转发引用），可以接收左值和右值。
- `std::forward<Args>(args)...` → 保留参数原本的“值类别”：
    - 如果调用时传的是左值 → 以左值传下去
    - 如果调用时传的是右值 → 以右值传下去（允许移动构造）

## 后续改进
- 该写法的缺点：
	- **递归写法繁琐**：需写终止分支，代码复杂。
	- **错误消息难懂**：展开过多时编译器错误堆栈很长。
	- **实例化膨胀**：每次展开都生成模板实例，编译时间/内存开销大。
	- **错误路径也会被编译（编译期检查问题）**：如果递归分支或某个展开分支包含对某些类型不合法的代码，编译器在实例化时可能仍会尝试编译那些分支并报错（除非用 SFINAE/enable_if/tag-dispatch 等技巧避免）
		- 这是 `if constexpr` 和折叠表达式出现前的痛点之一

- C14改进，可以利用auto推导返回值
```C++
//C++11
template<typename... Args>
auto concat_strings(Args&&... args) -> std::string { // 明确指定返回类型
    std::string s;
    using expander = int[];
    (void)expander{0, ((s += args), 0)...};
    return s;
}

//利用递归+decltype来推导类型
template<typename T>
T sum(T v) {
    return v;
}

template<typename T, typename... Args>
auto sum(T first, Args... rest) -> decltype(first + sum(rest...)) {
    return first + sum(rest...);
}


//C++14
template<typename... Args>
auto concat_strings(Args&&... args) { // C++14起允许返回类型 auto 推导
    std::string s;
    using expander = int[];
    (void)expander{0, ((s += args), 0)...};
    return s; // 编译器自动推导出返回值是 std::string
}

```

- C++17出现了折叠表达式
```C++
#include <iostream>

// 求和（注意：如果 args 为空包，这个写法会出错；见后说明）
template<typename... Ts>
auto sum(Ts... ts) {
    return (ts + ...); // 左折叠: ((t1 + t2) + t3) + ...
}

// 推荐的支持空包写法（用初值）
template<typename... Ts>
auto sum_safe(Ts... ts) {
    return (0 + ... + ts); // init + t1 + t2 + ...
}

// 打印（保持顺序）
template<typename... Ts>
void print(Ts&&... ts) {
    ((std::cout << std::forward<Ts>(ts) << ' '), ...);
    std::cout << '\n';
}

// all(true...): 逻辑与
template<typename... Ts>
bool all_true(Ts... ts) {
    return (true && ... && ts); // 对空包返回 true
}
```
