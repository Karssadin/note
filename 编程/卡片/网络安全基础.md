## 常见网络攻击

### 注入类

| 攻击 | 原理 | 防御 |
|------|------|------|
| **SQL 注入** | 恶意 SQL 嵌入查询 | 参数化查询、预编译 |
| **命令注入** | 将用户输入拼接到系统命令 | 禁用危险函数、白名单校验 |
| **XSS**（跨站脚本） | 注入恶意脚本到页面 | 输出转义、CSP 策略 |

### 请求伪造类

| 攻击 | 原理 | 防御 |
|------|------|------|
| **CSRF**（跨站请求伪造） | 借用已登录用户的 Cookie 发起请求 | CSRF Token、SameSite Cookie |
| **SSRF**（服务端请求伪造） | 让服务端发起对内网的请求 | URL 白名单、禁止访问内网 |

### 拒绝服务类

| 攻击 | 原理 | 防御 |
|------|------|------|
| **DDoS** | 大量流量淹没服务器 | CDN、流量清洗、限速 |
| **SYN Flood** | 发大量 SYN 不回 ACK 耗尽连接 | SYN Cookie、防火墙 |
| **CC 攻击** | 大量 HTTP 请求耗尽服务器资源 | 验证码、IP 限速、WAF |

### 中间人攻击（MITM）

攻击者插入通信双方之间，窃听或篡改数据。

**防御**：HTTPS（TLS）+ 证书固定（Certificate Pinning）

## HTTPS 安全机制（核心）

```
机密性：TLS 对称加密（AES）
完整性：HMAC 防篡改
身份验证：数字证书（CA 签名）
```

## OWASP Top 10（高频考点）

1. 访问控制失效
2. **密码学失败**（敏感数据未加密）
3. **注入**（SQL、命令、XSS）
4. 不安全设计
5. 安全配置错误
6. 易受攻击组件
7. 身份识别和认证失败
8. 软件和数据完整性失败
9. 安全日志和监控失败
10. **SSRF**

## 安全头部

```http
Content-Security-Policy: default-src 'self'  # 防 XSS
X-Frame-Options: DENY                         # 防点击劫持
Strict-Transport-Security: max-age=31536000   # 强制 HTTPS
X-Content-Type-Options: nosniff               # 防 MIME 嗅探
```
