## 完美转发（Perfect Forwarding）

完美转发是 C++11 引入的技术，使**泛型函数**在转发参数时能完整保留参数的**左值/右值属性**，不额外拷贝。

## 问题：不完美转发

```cpp
void process(int& x)  { std::cout << "lvalue\n"; }
void process(int&& x) { std::cout << "rvalue\n"; }

template<typename T>
void wrapper(T val) {
    process(val);  // val 是具名变量，永远是左值！
}

wrapper(42);      // 期望输出 rvalue，实际输出 lvalue ❌
```

## 解决：转发引用 + std::forward

```cpp
template<typename T>
void wrapper(T&& val) {              // T&& 是"转发引用"（万能引用）
    process(std::forward<T>(val));   // 按原始类型转发
}

int x = 1;
wrapper(x);   // T=int&,  val 是 lvalue → process(int&)  ✓
wrapper(42);  // T=int,   val 是 rvalue → process(int&&) ✓
```

## 引用折叠规则

`T&&` 与实际类型组合时发生引用折叠：

| 传入类型 | T 推导为 | T&& 结果 |
|---------|---------|---------|
| 左值 `int` | `int&` | `int& &&` → `int&` |
| 右值 `int` | `int` | `int&&` |

规则：只有 `T&& &&` 结果为 `&&`，其余均折叠为 `&`。

## std::forward 原理

```cpp
template<typename T>
T&& forward(std::remove_reference_t<T>& arg) {
    return static_cast<T&&>(arg);
}
// T=int&  → 返回 int& （左值引用）
// T=int   → 返回 int&&（右值引用）
```

`std::forward<T>` 根据 T 的推导类型决定是否转换为右值引用。

## 实际应用：工厂函数

```cpp
template<typename T, typename... Args>
std::unique_ptr<T> make_unique(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}

auto p = make_unique<MyClass>(1, "hello", std::move(v));
// int 1 作为右值传入，"hello" 作为右值，v 被 move 后传入
```

## 与 std::move 的区别

| | `std::move` | `std::forward` |
|-|-------------|----------------|
| 功能 | 无条件转换为右值引用 | 按 T 的推导有条件转发 |
| 使用场景 | 明确想移动资源时 | 泛型代码转发参数时 |
| T 的要求 | 不需要模板 | 需要在模板中使用 |
