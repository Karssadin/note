- [77. 组合](https://leetcode.cn/problems/combinations)
- backtracking（递归函数）通过不断调用自己一直往深处遍历，总会遇到叶子节点，遇到了叶子节点就要返回。
- backtracking的下面部分就是回溯的操作了，撤销本次处理的结果。
- 如果是一个集合来求组合的话，就需要startIndex。多个集合求组合的话就不需要了

```C
vector<vector<int>> result; // 存放符合条件结果的集合
vector<int> path; // 用来存放符合条件单一结果
void backtracking(int n, int k, int startIndex){
    if(path.size() == k)
        result.push_back(path);
    for(int i = startIndex; i <= n; i++){
        path.push_back(i); // 处理节点
        backtracking(n, k, i + 1); // 递归
        path.pop_back(); // 回溯，撤销处理的节点
    }
}
vector<vector<int>> combine(int n, int k) {
    backtracking(n, k, 1);
    return result;
}
```

- 剪枝优化

```C
//当前已经有path.size()个值了，共计还需要k - path.size()个，
// +1 4 - 2 = 2，但是+ 1从3开始就行了，因为是个左闭的区间，
// n - (k - path.size()) + 1之后的元素个数 已经不足我们需要的元素个数了，那么就没有必要搜索了
for(int i = startIndex; i <= n - (k - path.size()) + 1; i++){
    path.push_back(i); // 处理节点
    backtracking(n, k, i + 1); // 递归
    path.pop_back(); // 回溯，撤销处理的节点
}
```
