## 字符处理函数

```cpp
#include <cctype>

isdigit(c)   // 是否为数字
isalpha(c)   // 是否为字母
isupper(c)   // 是否为大写字母
islower(c)   // 是否为小写字母
isalnum(c)   // 是否为字母或数字
isspace(c)   // 是否为空白字符
toupper(c)   // 转为大写
tolower(c)   // 转为小写
```

## string 常用操作

```cpp
#include <string>

string s = "hello";
s.size();                    // 长度 5
s.substr(0, 2);              // "he"
s.append(" world");          // "hello world"
s.replace(1, 1, "b");       // "hbllo"
s.find("ll");                // 2（未找到返回 string::npos）
s.compare("hello");          // 0 表示相等
s.push_back('!');
s.pop_back();
s.insert(0, "hi ");         // "hi hello"
s.erase(0, 3);              // "hello"
```


## 面试常见技巧

- **双指针反转**：`reverse(s.begin(), s.end())`
- **滑动窗口**：寻找最长/最短子串
- **KMP 算法**：O(n+m) 模式匹配，核心是构建 next 数组
- **回文判断**：双指针从两端向中间或中心扩展法
