- 常见统计信息及功能：

| 统计项                            | 含义                  | 功能                               | 获取方式                                                               |
| ------------------------------ | ------------------- | -------------------------------- | ------------------------------------------------------------------ |
| Row Count                      | 表中总行数               | 估算扫描代价、join 代价、排序代价              | select count(*)                                                    |
| NDV（Number of Distinct Values） | 不同值（Distinct）的个数    | 估算列的**选择率**，影响过滤条件的行数估计          | count(*) group by或者HyperLogLog 或采样近似估计                             |
| Distinct 值                     | 与 NDV 相同，但通常指具体取值集合 | MCV列表                            | 与NDV相同                                                             |
| NULL值数量                        | 列中 NULL 的数量或比例      | `col IS NULL` 的选择率               | `COUNT(*) - COUNT(col)` 或 `SUM(CASE WHEN col IS NULL THEN 1 END)`  |
| Min / Max 值                    | 列中最大值和最小值           | 用于谓词范围过滤（例如 `WHERE col > 10`）的估算 | `MIN(col)` / `MAX(col)`                                            |
| MCV（Most Common Values）        | 最常见的若干取值和频率         | 提高热门值过滤条件的估算精度                   | `SELECT col, COUNT(*) GROUP BY col ORDER BY COUNT(*) DESC LIMIT N` |
| 直方图（Histogram）                 | 按区间分桶的值分布统计         | 用于估算范围谓词的选择率                     | 基于采样结果按区间构建分桶，如等宽或等深算法                                             |
