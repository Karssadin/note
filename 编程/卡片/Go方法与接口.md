# Go方法与接口

Go 没有 class 继承体系，主要用结构体、方法、接口和组合表达抽象。

1. 方法
	1. 方法是带接收者的函数
	2. 接收者可以是值类型或指针类型
	3. 指针接收者常用于修改对象或避免大对象拷贝
