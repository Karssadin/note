# 关系数据库模型

关系数据库模型用二维表表示数据，用关系代数和 SQL 描述查询与变换。

## 核心概念

1. 关系：一张表。
2. 元组：表中的一行。
3. 属性：表中的一列。
4. 域：属性可取值的集合。
5. 主键：唯一标识元组的属性或属性组合。
6. 外键：引用其他关系主键的属性。

## 特点

1. 数据以逻辑表形式组织，屏蔽物理存储细节。
2. 查询语言声明式，用户描述要什么，而不是怎么执行。
3. 通过完整性约束维护数据一致性。
4. 优化器负责选择具体执行计划。
