- 通过指针间接访问内存
- 变量名就是对应着一个地址，输出变量名，就是输出对应地址中的值，而指针变量，存储地址，指针变量也有地址。指针变量名也就是地址值的地址

```C
//定义: 数据类型* 变量名
int *ptr;
//*p 解引用,解析
int *p=&a;
//cout<<a;和cout<<*p一致
```

- 32位占4字节，64位占8字节
- 利用指针访问数组中元素
- 利用p指针指向数组名
- (p++)
- 利用**指针来做函数的参数**，可以实现**形参来改变实参**的值，把**实参的地址**传递给形参即可
