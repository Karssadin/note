`<algorithm>` 中的堆操作函数，在数组/vector 上维护堆结构。`priority_queue` 底层就是用这些算法实现的。

## make_heap

将序列转为堆（默认大根堆），O(n)。

```cpp
vector<int> v = {3, 1, 4, 1, 5, 9};
make_heap(v.begin(), v.end());          // 大根堆
make_heap(v.begin(), v.end(), greater<int>());  // 小根堆
// v[0] 是最大值
```

## push_heap

在堆尾 push_back 新元素后，调用 push_heap 上浮调整，O(log n)。

```cpp
v.push_back(7);
push_heap(v.begin(), v.end());
```

## pop_heap

将堆顶移到末尾，剩余部分重新调整为堆，O(log n)。配合 pop_back 真正删除。

```cpp
pop_heap(v.begin(), v.end());   // 最大值移到 v.back()
v.pop_back();                    // 真正删除
```

## sort_heap

对堆进行堆排序，结果为升序，O(n log n)。调用后不再是堆。

```cpp
sort_heap(v.begin(), v.end());  // v 变为升序
```

## is_heap / is_heap_until

```cpp
bool ok = is_heap(v.begin(), v.end());
auto it = is_heap_until(v.begin(), v.end());  // 第一个破坏堆性质的位置
```

## 与 priority_queue 的关系

`priority_queue` 内部就是 `vector` + `make_heap` / `push_heap` / `pop_heap`。直接使用堆算法更灵活（可以随时访问底层数组、自定义操作），priority_queue 更封装（只能访问堆顶）。
