### 谓词

- 返回bool类型的仿函数叫谓词
- operator()接收一个参数，叫一元谓词
- Operator()接收两个参数，叫二元谓词

### 一元谓词

```C
class GreaterFive{
public:
	bool operator(int val)
		return val>5;
};
//查找容器中有没有大于5的数字
find_if(v.begin(),v.end(),GreaterFive());//创建匿名函数对象

//在find_if中就是在遍历时候进行调用该函数对象，如果有，就会返回迭代器的位置，如果没找到，就会返回end();
```

### 二元谓词

```C
class MySort{
public:
	bool operator()(int v1,int v2)
		return v1>v2;
};

//默认从小到大，改成从大到小
sort(v.begin(),v.end(),MySort());
```
