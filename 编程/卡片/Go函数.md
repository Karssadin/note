# Go函数

Go 函数是一等值，可以赋值给变量、作为参数传递，也可以作为返回值。

```go
func add(a int, b int) int {
	return a + b
}
```

## 特点

1. 支持多返回值，常用于返回结果和 `error`。
2. 参数按值传递，传入切片、map、channel 时复制的是头部或引用描述。
3. 支持命名返回值，但复杂函数中应谨慎使用。
4. 支持匿名函数和闭包，闭包会捕获外部变量。
5. 不支持默认参数和函数重载。
