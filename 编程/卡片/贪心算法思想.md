## 核心思想

每一步都选择**当前看来最优**的方案，不回溯、不考虑全局。贪心成立的条件：

1. **贪心选择性质**：局部最优选择能导致全局最优
2. **最优子结构**：问题的最优解包含子问题的最优解

## 解题框架

1. 将问题分解为多个决策步骤
2. 确定每步的贪心策略（排序、选最大/最小等）
3. **证明**贪心策略的正确性（交换论证法 / 反证法）
4. 实现

## 经典问题

| 问题 | 贪心策略 |
|------|----------|
| 活动选择 / 区间调度 | 按结束时间排序，优先选结束最早的 |
| 跳跃游戏 | 维护当前能到达的最远位置 |
| 分发饼干 | 小饼干满足小胃口 |
| 加油站 | 如果总油量 ≥ 总消耗，则一定存在解 |
| Huffman 编码 | 每次合并频率最小的两个节点 |
| 最小生成树（Kruskal） | 按边权排序，贪心选不成环的最小边 |
| Dijkstra 最短路 | 每次选距离源点最近的未访问节点 |

## 贪心 vs 动态规划

贪心不一定正确——能用贪心的问题一定能用 DP，但 DP 能解决的问题贪心不一定能解。

反例：0-1 背包问题，按性价比贪心选择不一定得到最优解，必须用 DP。

## 常见证明方法

- **交换论证**：假设存在一个最优解不符合贪心策略，通过交换操作将其转化为贪心解且不变差
- **反证法**：假设贪心解不是最优的，推出矛盾
- **数学归纳**：证明每一步贪心后，剩余问题的最优解仍然可用贪心得到
