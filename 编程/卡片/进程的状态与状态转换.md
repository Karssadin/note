# 进程的状态与状态转换

进程的基本状态包括就绪态、运行态、阻塞态，扩展模型中还会包含新建态和终止态。

## 基本状态

1. 就绪态：进程已获得除 CPU 以外的必要资源，等待调度器分配 CPU。
2. 运行态：进程正在 CPU 上执行。
3. 阻塞态：进程等待 I/O、资源或事件完成，暂时不能继续执行。
4. 新建态：进程正在创建，还未进入就绪队列。
5. 终止态：进程执行结束或被终止，等待系统回收资源。

## 状态转换

1. 就绪 -> 运行：调度器选择该进程并分配 CPU。
2. 运行 -> 阻塞：进程等待 I/O、资源或事件。
3. 阻塞 -> 就绪：等待事件完成，进程重新具备运行条件。
4. 运行 -> 就绪：时间片用完，或被更高优先级进程抢占。
5. 运行 -> 终止：进程正常结束或异常退出。
