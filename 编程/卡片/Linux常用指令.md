- pwd
    - 打印终端当前目录
    - pwd
- ls
    - ls
        - 列出当前目录下文件/文件夹的名称
    - ls [路径]
        - 列出指定路径下文件/文件夹的名称
        - 可以使用绝对路径、相对路径
    - **选项**
        - -l：表示list，以详细列表的形式进行展示
            - -表示文件
            - d表示文件夹类型文件
            - .表示隐藏文件
        - -a：显示所有的文件/文件夹，包含隐藏
        - -h：以较高的可读形式显示
- cd
    - 切换工作目录
    - cd、cd ~：进入当前家目录
    - cd [相对路径]
        - cd ..
    - cd [绝对路径]
    - cd -
- mkdir
    - 创建目录
    - mkdir 路径
        - 可以一次性创建多个目录
    - 选项
        - -p：逐级创建多层不存在的目录
- touch
    - touch指定文件的修改时间时间为当前时间
    - 可以实现创建新文件
    - touch [路径]
        - 可以创建多个文件
- rm
    - 删除文件/目录
    - 绝对路径、相对路径都可以
    - rm [选项] 需要移除的文件路径
    - rm [选项] 需要移除的路径
        - -rf
- cp
    - 复制文件/文件夹到指定位置
    - cp 文件路径 被复制到的路径
    - cp -r 文件夹路径 被复制到的路径
        - 递归复制
- mv
    - 移动文件到新的位置，或重命名文件
    - mv myfile /myfile：从当前目录移动到根目录
    - mv myforder /myforder
    - mv myfile /myfile_：重命名文件
- man
    - 包含Linux中全部命令手册，查看命令手册，按q退出
    - man [命令]
- reboot
- shutdown
    - shutdown -h [时间]
        - now
        - shutdown - h 时首先会通知当前登陆系统的用户，结束login.并会杀掉所有进程（有信号SIGTERM），可以让进程更安全的关闭。然后再调用init 0。
        - init 0 就直接去执行/etc/rc.d/rc1.d里面的脚本了。
        - poweroff是halt的符号连接(等于halt -p) halt -p 就是在系统关闭后再关掉电源。halt -p -f 等于直接拔电
    - -r：关机并重启
- init 0：关机并重启
- ctrl + l ： 清屏
