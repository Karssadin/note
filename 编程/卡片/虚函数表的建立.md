## 编译期：vtable 的生成

编译器为**每个含有虚函数的类**生成一张静态的虚函数表（vtable），存放在可执行文件的 **`.rodata`（只读数据段）** 中：

```
vtable 内容结构：
┌─────────────────────────────────┐
│ [0] RTTI 信息指针（type_info*） │
│ [1] 虚析构函数地址               │
│ [2] 虚函数1地址                  │
│ [3] 虚函数2地址                  │
│ ...                              │
└─────────────────────────────────┘
```

**派生类 vtable 的生成规则**：
1. 从基类 vtable **复制一份**
2. 对于派生类**重写**的虚函数，将对应槽位的函数指针替换为派生类的实现
3. 对于派生类**新增**的虚函数，追加到 vtable 末尾

```cpp
class Base {
    virtual void f();  // vtable[0] = Base::f
    virtual void g();  // vtable[1] = Base::g
};

class Derived : public Base {
    void f() override; // vtable[0] = Derived::f（覆盖）
    virtual void h();  // vtable[2] = Derived::h（新增）
    // g() 未重写，vtable[1] 仍指向 Base::g
};
```

## 运行期：vptr 的设置（构造函数）

每个对象中有一个隐藏的**虚表指针（vptr）**，由构造函数负责设置。

**关键：vptr 在构造函数执行期间指向当前类的 vtable，而非最终派生类。**

```cpp
class A {
public:
    A() { vptr = &A::vtable; }  // 伪代码
    virtual void f() { puts("A::f"); }
};

class B : public A {
public:
    B() : A() {            // 先调用 A()，此时 vptr → A::vtable
        vptr = &B::vtable; // B 构造函数：vptr → B::vtable
    }
    void f() override { puts("B::f"); }
};
```

**构造顺序示意**（`new B()`）：
```
1. 分配内存
2. 调用 A::A() → vptr = &A::vtable
3. 调用 B::B() → vptr = &B::vtable
4. B 对象创建完成，vptr 最终指向 B::vtable
```

**构造函数中调用虚函数的陷阱**：

```cpp
class A {
public:
    A() { f(); }              // ⚠️ 此时 vptr 指向 A::vtable
    virtual void f() { puts("A::f"); }
};

class B : public A {
public:
    void f() override { puts("B::f"); }
};

B b;  // 输出 "A::f"，而非 "B::f"！
// 原因：A() 执行时，vptr 还指向 A::vtable，B::f 尚未绑定
```

## 析构期：vptr 的还原

析构顺序与构造相反，vptr 在每一级析构函数开始时还原为**当前类**的 vtable：

```
析构 B 对象：
1. 调用 B::~B() → vptr = &B::vtable（析构 B 特有资源）
2. 调用 A::~A() → vptr = &A::vtable（析构 A 的资源）
3. 释放内存
```

这保证了析构函数中调用虚函数时，行为与对象当前的析构阶段一致。

## 多继承场景

多继承时，对象中有**多个 vptr**，每个基类对应一个：

```cpp
class A { virtual void fa(); };
class B { virtual void fb(); };
class C : public A, public B {
    void fa() override;
    void fb() override;
};

// C 对象内存布局：
// [ vptr_A → C::vtable_A ]  (for A 部分)
// [    A 的数据成员        ]
// [ vptr_B → C::vtable_B ]  (for B 部分)
// [    B 的数据成员        ]
// [    C 自身的数据成员    ]
```

## 总结

| 阶段 | 操作 | 负责者 |
|------|------|--------|
| 编译期 | 生成 vtable，放入 `.rodata` | 编译器 |
| 对象构造 | 逐层设置 vptr（从基类到派生类） | 构造函数 |
| 对象析构 | 逐层还原 vptr（从派生类到基类） | 析构函数 |
| 虚函数调用 | 通过 vptr 查表获取函数地址 | CPU 间接跳转 |
