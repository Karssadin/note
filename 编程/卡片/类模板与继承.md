- 子类继承父类时，在继承base时需要指定父类中T的类型
- 如果想灵活指定父类中的T类型，子类也可以定义为模板类
- 如果不指定的话，不知道分配多少空间

```C
template<typename T>
class Base{
	T m;
};
//错误
class Son:public:Base{

};

class Son:public:Base<int>{

};
template<typename T1,typename T2>
class Son:public:Base<T1>{
	T2 obj;
};
```
