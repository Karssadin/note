`<algorithm>` 中的分区算法，将序列按条件分为两部分：满足条件的在前，不满足的在后。

## partition

不稳定分区，满足谓词的元素移到前面，返回分区边界迭代器。

```cpp
auto it = partition(v.begin(), v.end(), [](int x){ return x % 2 == 0; });
// [v.begin(), it) 全是偶数，[it, v.end()) 全是奇数
```

## stable_partition

稳定分区，保持每组内元素的相对顺序。

```cpp
stable_partition(v.begin(), v.end(), [](int x){ return x > 0; });
```

## is_partitioned

判断序列是否已按谓词分区。

```cpp
bool ok = is_partitioned(v.begin(), v.end(), [](int x){ return x > 0; });
```

## partition_point

对已分区的序列，返回分区边界（第一个不满足谓词的位置），O(log n)。

```cpp
auto it = partition_point(v.begin(), v.end(), [](int x){ return x < 5; });
```

## 应用场景

- 快速排序的核心操作就是 partition
- 将数据按条件分组后分别处理
- 荷兰国旗问题的变体
