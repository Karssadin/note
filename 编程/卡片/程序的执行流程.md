C/C++ 程序从源代码到运行结果的完整流程：

1. **预处理**：展开 `#include`、`#define`，处理条件编译 `#ifdef`，生成 `.i` 文件
2. **编译**：将预处理后的源码翻译为汇编代码 `.s`，进行语法分析、语义分析和优化
3. **汇编**：将汇编代码翻译为机器码，生成目标文件 `.o`（可重定位文件）
4. **链接**：将多个目标文件与库文件合并，解析符号引用，生成可执行文件
5. **加载**：操作系统将可执行文件映射到虚拟内存，设置栈、堆、代码段、数据段
6. **执行**：从 `main()` 入口开始执行；在此之前，运行时会先执行全局对象的构造函数

```
源码 .cpp → 预处理 .i → 编译 .s → 汇编 .o → 链接 → 可执行文件 → 加载运行
```

- 全局变量和静态变量在 `main()` 之前初始化
- `atexit()` 注册的函数和全局对象的析构函数在 `main()` 返回后执行
- C++ 中全局对象的构造顺序在同一编译单元内按定义顺序，跨编译单元顺序未定义
