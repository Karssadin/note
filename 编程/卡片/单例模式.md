- 创建型模式
- 保证⼀个类仅有⼀个实例，并提供⼀个访问它的全局访问点
- 私有的构造函数：确保外部不能通过 new 创建该类的实例。
- 一个私有静态实例：这是该类唯一的实例。
- 一个公共的静态方法：供外部获取该类的唯一实例。
- 懒汉式：它在首次被引用时才被实例化，这样可以实现延迟加载。线程不安全
- 饿汉式：在类加载时就完成了初始化，所以类加载较慢，但获取对象的速度快。造成资源浪费
- 静态内部类实现：创建一个静态内部类，内部类中有一个变量，创建当前类的实例化，提供接口调用，返回引用

```C
class Singleton {
private:
    static Singleton* instance;
    // 私有构造函数，确保外部不能使用 new 创建此类的实例
    Singleton() {}

public:
    // 删除复制构造函数和赋值操作
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
    // 公共静态方法，用于获取该类的唯一实例
    static Singleton* getInstance() {
        if (instance == nullptr) {
            instance = new Singleton();
        }
        return instance;
    }
};
// 初始化静态成员
Singleton* Singleton::instance = nullptr;

// 获取单例实例的函数
static Singleton* getInstance() {
    if (!instance) {  // 首先判断实例是否已经存在
        std::unique_lock<std::mutex> lock(mtx);  // 上锁
        if (!instance) {
            instance = new Singleton();
        }
    }
    return instance;
}
```

## Meyer's 单例（C++11 推荐）

局部静态变量的初始化在 C++11 中是线程安全的：

```cpp
class Singleton {
public:
    static Singleton& getInstance() {
        static Singleton instance;  // 线程安全（C++11 起）
        return instance;
    }
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
private:
    Singleton() {}
};
```

## 双重检查锁定（DCLP）

```cpp
class Singleton {
    static std::atomic<Singleton*> instance;
    static std::mutex mtx;
public:
    static Singleton* getInstance() {
        Singleton* p = instance.load(std::memory_order_acquire);
        if (!p) {
            std::lock_guard<std::mutex> lock(mtx);
            p = instance.load(std::memory_order_relaxed);
            if (!p) {
                p = new Singleton();
                instance.store(p, std::memory_order_release);
            }
        }
        return p;
    }
};
```

## 三种实现对比

| 方式 | 线程安全 | 懒加载 | 推荐 |
|------|----------|--------|------|
| 饿汉式 | 是 | 否 | 不推荐（资源浪费） |
| 懒汉式（无锁） | 否 | 是 | 禁止 |
| DCLP（atomic） | 是 | 是 | 可用 |
| Meyer's 局部静态 | 是 | 是 | **推荐** |
