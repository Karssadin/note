## 信号的概念

**信号（Signal）** 是 Unix/Linux 中进程间通信的一种**异步通知机制**，用来通知进程某个事件已经发生。

当信号发送给进程时，进程正常执行流被中断，可能发生：
- 进程**终止**（默认行为，如 SIGTERM）
- 进程终止并生成 **core dump** 文件（SIGSEGV、SIGABRT 等）
- **忽略**该信号（signal(SIGPIPE, SIG_IGN)）
- 调用**信号处理函数**（signal handler）

## 常用信号列表

| 信号 | 编号 | 默认行为 | 含义 |
|------|------|----------|------|
| `SIGINT` | 2 | 终止 | Ctrl+C，中断进程 |
| `SIGQUIT` | 3 | 终止+core | Ctrl+\，退出并生成 core |
| `SIGKILL` | 9 | 终止 | **不可捕获/忽略**，强制终止 |
| `SIGSEGV` | 11 | 终止+core | 段错误（非法内存访问） |
| `SIGPIPE` | 13 | 终止 | 写入关闭的管道 |
| `SIGTERM` | 15 | 终止 | 请求终止（可被捕获，优雅退出） |
| `SIGCHLD` | 17 | 忽略 | 子进程状态改变（终止/暂停） |
| `SIGSTOP` | 19 | 暂停 | **不可捕获/忽略**，暂停进程 |
| `SIGCONT` | 18 | 继续 | 恢复暂停的进程 |
| `SIGALRM` | 14 | 终止 | `alarm()` 定时器超时 |
| `SIGUSR1/2` | 10/12 | 终止 | 用户自定义信号 |

## 注册信号处理函数

### signal()（简单但不推荐）

```cpp
#include <signal.h>

void handler(int sig) {
    // 处理信号
    write(STDOUT_FILENO, "Caught SIGINT\n", 14);  // 用 write 不用 printf
}

signal(SIGINT, handler);   // 注册 Ctrl+C 处理
signal(SIGTERM, handler);  // 注册终止处理
signal(SIGPIPE, SIG_IGN);  // 忽略 SIGPIPE
```

### sigaction()（推荐，更安全可移植）

```cpp
#include <signal.h>

void handler(int sig, siginfo_t* info, void* context) {
    // sig: 信号编号
    // info: 信号详细信息（发送者 PID 等）
}

struct sigaction sa;
sa.sa_sigaction = handler;
sa.sa_flags = SA_SIGINFO | SA_RESTART;  // SA_RESTART：被信号中断的系统调用自动重启
sigemptyset(&sa.sa_mask);              // 处理期间不屏蔽其他信号
sigaction(SIGINT, &sa, nullptr);
```

**`signal()` vs `sigaction()` 的区别**：
- `signal()` 行为在不同系统上不一致（处理后是否重置为默认）
- `sigaction()` 行为明确、可控，可获取更多信号信息，是 POSIX 标准推荐

## 信号屏蔽（信号掩码）

```cpp
#include <signal.h>

sigset_t mask, old_mask;
sigemptyset(&mask);
sigaddset(&mask, SIGINT);   // 屏蔽 SIGINT
sigaddset(&mask, SIGTERM);  // 屏蔽 SIGTERM

// 屏蔽信号（进入临界区）
sigprocmask(SIG_BLOCK, &mask, &old_mask);
// ... 临界区代码 ...
// 恢复屏蔽（离开临界区）
sigprocmask(SIG_SETMASK, &old_mask, nullptr);
```

## 异步信号安全（Async-Signal-Safe）

信号处理函数可能**随时打断**程序执行，因此：

- **禁止调用非异步信号安全函数**：`printf`、`malloc`、`free`、STL 容器操作等
- **可安全调用**：`write()`、`_exit()`、`sem_post()` 等（POSIX 定义的 async-signal-safe 函数）

```cpp
// ❌ 危险：printf 不是异步信号安全的
void handler(int) { printf("caught signal\n"); }

// ✅ 安全：write 是异步信号安全的
void handler(int) { write(STDOUT_FILENO, "caught\n", 7); }

// ✅ 实践：用 volatile sig_atomic_t 标志，在主循环中处理
volatile sig_atomic_t g_stop = 0;
void handler(int) { g_stop = 1; }
// 主循环：while (!g_stop) { ... }
```

## SIGCHLD 与僵尸进程

```cpp
// 父进程通过捕获 SIGCHLD 回收子进程
void sigchld_handler(int) {
    int status;
    pid_t pid;
    // 用 WNOHANG 避免阻塞，循环回收所有已结束子进程
    while ((pid = waitpid(-1, &status, WNOHANG)) > 0) {
        // 子进程 pid 已退出，status 包含退出码
    }
}

struct sigaction sa;
sa.sa_handler = sigchld_handler;
sa.sa_flags = SA_RESTART | SA_NOCLDSTOP;
sigemptyset(&sa.sa_mask);
sigaction(SIGCHLD, &sa, nullptr);
```

## 信号的来源

- **硬件异常**：访问非法地址（SIGSEGV）、除零（SIGFPE）
- **键盘**：Ctrl+C（SIGINT）、Ctrl+Z（SIGTSTP）、Ctrl+\（SIGQUIT）
- **kill 命令/系统调用**：`kill -9 PID`、`kill(pid, SIGTERM)`
- **软件条件**：管道关闭（SIGPIPE）、定时器（SIGALRM）、子进程终止（SIGCHLD）
