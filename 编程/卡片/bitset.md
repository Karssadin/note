`std::bitset<N>` 是固定大小为 N 的位集合，每个 bool 只占 1 bit（普通 bool 数组每个占 1 byte），空间节省 8 倍。

## 创建

```cpp
bitset<8> b1;              // 00000000
bitset<8> b2(0b10110011);  // 10110011
bitset<8> b3("10110011");  // 从字符串创建
```

## 常用操作

| 操作 | 说明 |
|------|------|
| `b[k]` | 访问第 k 位 |
| `b.set()` | 全部置 1 |
| `b.set(k, v)` | 第 k 位设为 v |
| `b.reset()` | 全部置 0 |
| `b.reset(k)` | 第 k 位置 0 |
| `b.flip()` | 全部取反 |
| `b.flip(k)` | 第 k 位取反 |
| `b.test(k)` | 第 k 位是否为 1（带越界检查） |
| `b.count()` | 返回 1 的个数 |
| `b.any()` | 是否至少有一个 1 |
| `b.none()` | 是否全为 0 |
| `b.all()` | 是否全为 1（C++11） |
| `b.size()` | 返回 N |

## 位运算

```cpp
bitset<8> a("10101010"), b("11001100");
auto c = a & b;   // 10001000
auto d = a | b;   // 11101110
auto e = a ^ b;   // 01100110
auto f = ~a;       // 01010101
auto g = a << 2;   // 10101000
```

## 与手动位运算的对比

- bitset 更安全（有越界检查），更易读
- 手动位运算更灵活（不限制固定大小），性能在极端场景下可能更好
- bitset 的 N 必须是编译期常量
