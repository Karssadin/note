- `int mid = left + (right - left) / 2`
- 在区间内部查找`x`在哪个位置，判断一个条件是否满足，要更新`l、r、mid`让答案在区间内部，接着判断，最后的`l、r`就是结果或者是未找到（未找到的话，区间为1，结果不对。就是不满足条件）
- 当我们将区间`[l, r`]划分成`[l, mid]`和`[mid + 1, r]`时，其更新操作是`r = mid`或者`l = mid + 1;`，计算`mid`时不需要加1
- 当我们将区间`[l, r]`划分成`[l, mid - 1]`和`[mid, r]`时，其更新操作是`r = mid - 1`或者`l = mid`;，此时为了防止死循环，计算`mid`时需要加1
    - `[l, mid - 1]`与 `[mid, r]`中如果 `mid` 下取整，在区间只有2个数的时候，`mid`的值等于`left`，一旦进入分支`[mid, r]` 区间不会再缩小，出现死循环,将一直是`[mid, r]`
    - 解决办法：把取中间数的方式改成`int mid = left + (right - left + 1) / 2`
- 浮点数的二分就比整数的简单点，因为不用考虑边界值和中间点是否+1之类
- 长度区间足够小，区间比要求的是多2个数量级就可以，要求输出6位小数，用8位精度来做
- 使用float可能会超时，因为精度不够，找不到最终结果
- 换成double精度就可以

```C++
int left = 0, right = nums.size() - 1;
while(left <= right){
    int mid = left + (right - left) / 2;
    if(nums[mid] == target)
        return mid;
    else if(nums[mid] < target)
        left = mid + 1;
    else
        right = mid - 1;
}
```

```C++
int l = 0, r = nums.size() -1;
while (l <= r){
    int mid = (l + r) >> 1;
    if (target == nums[mid])
        return mid;
    if (nums[l] <= nums[mid])
        if (target >= nums[l] && target < nums[mid])
            r = mid-1;
        else
            l = mid+1;
    else
        if (target > nums[mid] && target <= nums[r])
            l = mid +1;
        else
            r = mid -1;
}
```

- [35. 搜索插入位置](https://leetcode.cn/problems/search-insert-position)
- 题目要我们返回第1个大于等于目标元素的下标
- 如果当前 mid 看到的数值严格小于 target，那么 mid 以及 mid 左边的所有元素就一定不是「插入元素的位置」，因此下一轮搜索区间是 [mid + 1..right]，下一轮把 left 移动到 mid + 1 位置，因此设置 left = mid + 1
- 否则，如果 mid 看到的数值大于等于 target，那么 mid 可能是「插入元素的位置」，mid 的右边一定不存在「插入元素的位置」。如果 mid 的左边不存在「插入元素的位置」，我们才可以说 mid 是「插入元素的位置」。因此下一轮搜索区间是 [left..mid]，下一轮把 right 移动到 mid 位置，因此设置 right = mid。
