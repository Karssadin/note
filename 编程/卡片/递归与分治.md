## 递归

函数调用自身来解决问题。每个递归必须满足：

1. **基准条件（Base Case）**：终止递归的条件
2. **递推关系（Recursive Case）**：将问题缩小为子问题

```cpp
int factorial(int n) {
    if (n <= 1) return 1;        // 基准条件
    return n * factorial(n - 1); // 递推
}
```

### 递归的代价

- 每次调用占用栈帧空间，深度过大会**栈溢出**
- 可用**尾递归优化**或改写为**迭代**解决
- 重复子问题可用**记忆化**优化（→ 动态规划）

## 分治

将问题**分解**为若干同类子问题，**递归**求解后**合并**结果。三步框架：

1. **Divide**：拆分为规模更小的子问题
2. **Conquer**：递归解决子问题
3. **Merge**：合并子问题的解

### 经典应用

| 算法 | 分解方式 | 合并方式 |
|------|----------|----------|
| [[归并排序]] | 从中间一分为二 | 双指针合并有序数组 |
| [[快速排序]] | 按 pivot 划分 | 无需合并（原地） |
| 二分查找 | 取中间值比较 | 无需合并 |
| 大整数乘法（Karatsuba） | 拆高低位 | 组合乘积 |
| 最近点对 | 按 x 坐标分 | 跨界检查 |

### 复杂度分析：主定理

对于 `T(n) = aT(n/b) + O(nᵈ)`：

- `a`：子问题个数
- `b`：子问题缩减比例
- `d`：合并步骤的复杂度指数

归并排序：`T(n) = 2T(n/2) + O(n)` → a=2, b=2, d=1 → `d = log_b(a)` → O(n log n)

## 递归 vs 迭代

| 维度 | 递归 | 迭代 |
|------|------|------|
| 可读性 | 更直观（树结构问题） | 需要手动维护状态 |
| 空间 | O(深度) 调用栈 | 通常 O(1) |
| 性能 | 函数调用开销 | 更高效 |
| 适用 | 树/图遍历、分治 | 简单循环 |
