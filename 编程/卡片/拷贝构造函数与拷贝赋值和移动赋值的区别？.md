- 拷贝构造函数用于通过复制另一个对象来创建一个新对象，一般进行深拷贝，以确保新对象和原对象相互独立。
- 拷贝赋值运算符用于将一个对象的内容复制到另一个已存在的对象中，需要处理自赋值，并通常包括释放当前对象的资源、深拷贝新数据、更新对象状态等步骤。
- 移动赋值运算符用于将一个临时对象（右值）的资源转移到另一个已存在的对象中，需要处理自赋值，并通过资源转移（而不是复制）来提高性能，同时将源对象置于有效但未指定的状态。

```C++
//拷贝构造
ClassName(const ClassName& other) {
    this->data = new int[other.size];
    std::copy(other.data, other.data + other.size, this->data);
    this->size = other.size;
}

//拷贝赋值
ClassName& operator=(const ClassName& other) {
    if (this != &other) {  // 检查自赋值
        delete[] this->data;  // 释放当前对象的资源
        this->data = new int[other.size];
        std::copy(other.data, other.data + other.size, this->data);
        this->size = other.size;
    }
    return *this;
}

//移动赋值
ClassName& operator=(ClassName&& other) noexcept {
    if (this != &other) {  // 检查自赋值
        delete[] this->data;  // 释放当前对象的资源
        this->data = other.data;  // 移动other对象的数据
        this->size = other.size;
        other.data = nullptr;  // 将other对象置于有效但未指定的状态
        other.size = 0;
    }
    return *this;
}
```
