## TCP 主要特点

| 特点 | 说明 |
|------|------|
| **面向连接** | 通信前需三次握手建立连接，通信后四次挥手断开 |
| **可靠传输** | 通过序列号、ACK确认、超时重传保证数据不丢失、不乱序 |
| **流量控制** | 滑动窗口机制，防止发送方速率超过接收方处理能力 |
| **拥塞控制** | 慢启动、拥塞避免、快重传、快恢复，避免网络过载 |
| **有序性** | 数据段按序号排序，乱序到达时缓存等待重排 |
| **全双工** | 双方可同时发送和接收数据 |
| **字节流** | 无消息边界，可能发生粘包 |

## UDP 主要特点

| 特点 | 说明 |
|------|------|
| **无连接** | 发送前不需要建立连接，直接发送数据报 |
| **不可靠** | 不保证送达、不保证顺序、不重传 |
| **高速** | 头部仅 8 字节，无握手无确认，延迟低 |
| **支持广播/多播** | TCP 只支持单播，UDP 支持广播和多播 |
| **数据报** | 保留消息边界，一次 `sendto` 对应一次 `recvfrom` |
| **无拥塞控制** | 发送速率不受网络状态限制（可能造成网络拥塞） |

## 核心差异速记

```
TCP  = 可靠 + 有序 + 有连接 + 流控/拥塞控制 + 慢
UDP  = 不可靠 + 无连接 + 无流控 + 快
```
