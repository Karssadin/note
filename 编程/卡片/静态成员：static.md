- 添加关键字`static`，也有相应的访问权限
- 静态成员变量
    - 静态成员变量属于类的一部分，不依赖于特定的对象实例，它们在全局/静态内存区域中存储，所有类的对象共享同一份静态成员变量，相当于类域中的全局变量
    - 在编译阶段分配内存
    - 静态数据成员的类型可以是所属类的类型，而普通数据成员的类型只能是该类类型的指针或引用。
    - 类内声明，类外初始化，在类外初始化的时候不能出现static和访问规则关键字
        - 数据类型 **类::静态成员变量=值**
- 静态成员函数
    - 所有对象共享同一个静态成员函数
    - 成员函数的代码只存储一份，并且是在代码段中
    - 静态成员函数不占用对象的空间，在定义时属于类的一部分，不依赖于对象实例，通过对象来调用，以便操作对象的数据成员或执行与对象相关的操作
    - 静态成员函数与类相关联，但不操作类的具体对象。可以访问类的静态成员变量和其他静态成员函数，但不能访问非静态成员变量和非静态成员函数，因为它们没有特定的对象实例。
    - **静态成员函数只能访问静态成员变量,非静态成员变量无法被访问**（因为无法确定是哪个对象的变量），静态变量为共享
    - 静态成员函数的调用不需要类的对象，可以直接通过类名来调用
        - 不通过对象访问，**类名 ::**
    - 静态成员函数不能直接访问非静态成员变量：静态成员函数不依赖于特定的对象实例，而非静态成员变量是与对象实例相关联的。静态成员函数只能访问类的静态成员变量和其他静态成员函数，它们没有隐式的this指针，因此无法直接访问非静态成员变量

```C++
class MyClass {
public:
    int x; // 非静态成员变量
    static int y; // 静态成员变量

    void foo() {} // 非静态成员函数
    static void bar() {} // 静态成员函数
};

int MyClass::y = 0; // 静态成员变量初始化
```
