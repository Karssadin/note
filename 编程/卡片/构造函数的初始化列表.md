- 当你定义一个类的构造函数时，可以在构造函数体前，用冒号 `:` 指定成员变量的初始化方式，这就是 **构造函数初始化列表**。
    
- 它比在构造函数体内赋值效率更高，因为直接在对象构造时初始化，而不是先默认构造再赋值。
- 例如：
```C++
class MyClass {
    int x;
    std::string name;
public:
    MyClass(int a, std::string n) : x(a), name(std::move(n)) {
        // 构造函数体内可以做额外逻辑
    }
};
```
> 注意：**C++ 构造函数初始化列表中成员的初始化顺序是固定的，由成员在类中声明的顺序决定，而不是初始化列表中写的顺序**。


## 搭配initializer_list使用

```C++
#include <vector>

class MyVector {
    std::vector<int> data;
public:
    MyVector(std::initializer_list<int> il) : data(il) {}  // 构造函数接收 initializer_list
};

int main() {
    MyVector v{1,2,3};  // 调用 std::initializer_list 构造函数
}
```

## 必须使用构造函数初始化列表的场景

1. `const`成员：`const` 成员一旦定义就不可修改，只能在构造时初始化。
```C++
class MyClass {
    const int x;
public:
    MyClass(int val) : x(val) {}  // ✅ 必须使用初始化列表
};
```
- 在构造函数体内赋值是 **不允许的**
```C++
MyClass(int val) {
    x = val; // ❌ 编译错误
}
```
2. 引用类型成员： 引用必须在定义时初始化，之后不能重新绑定
```C++
class MyClass {
    int& ref;
public:
    MyClass(int& r) : ref(r) {}  // ✅ 必须在初始化列表中初始化
};
```
3. 没有默认构造函数的类类型成员: 
	1. 如果成员类没有默认构造函数，编译器无法在进入构造函数体前默认构造它。  
	2. 使用初始化列表可以直接调用带参构造函数。

```C++
class Member {
public:
    Member(int x) {}  // 没有默认构造函数
};

class MyClass {
    Member m;
public:
    MyClass(int val) : m(val) {}  // ✅ 必须使用初始化列表
};
```
- 如果在构造函数体内赋值，编译器会报错，因为 `m` 必须先被构造。
---

- 对于用户自定义类型，利用成员初始化列表效率高。
- 用户自定义类型如果使用类初始化列表，直接调用该成员变量对应的构造函数即完成初始化；如果在构造函数中初始化，因为 C++ 规定，对象的成员变量的初始化动作发生在进入构造函数本体之前，那么**在执行构造函数的函数体之前首先调用默认的构造函数为成员变量设初值**，在进入函数体之后，调用该成员变量对应的构造函数。因此，使用列表初始化会减少调用默认的构造函数的过程，效率高
