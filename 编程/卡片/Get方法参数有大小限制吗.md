- 浏览器限制：不同的浏览器对 URL 的长度有不同的限制。例如，早期的Internet Explorer 限制 URL 的长度为2,083个字符，而其他现代浏览器如Chrome 和 Firefox 允许的 URL 长度则更长。
- 服务器限制：不同的服务器和服务器软件对 GET请求的长度也有不同的限制。例如，Apache 服务器默认限制的 URL 长度是 8,192  
    字符，而 Nginx 则默认限制为 4,096 字符。
