C++17 引入结构化绑定（Structured Bindings），可以将聚合类型的成员直接解包到独立变量。

## 基本语法

```cpp
// 解包 pair
auto [key, value] = std::make_pair(1, "hello");

// 解包 tuple
auto [x, y, z] = std::make_tuple(1, 2.0, "str");

// 解包结构体
struct Point { int x, y; };
auto [px, py] = Point{10, 20};

// 解包数组
int arr[] = {1, 2, 3};
auto [a, b, c] = arr;
```

## 配合 range-for

```cpp
std::map<std::string, int> m = {{"a", 1}, {"b", 2}};

for (const auto& [key, value] : m) {
    std::cout << key << ": " << value << "\n";
}
```

## 引用绑定

```cpp
auto& [x, y] = point;   // 引用绑定，修改会影响原对象
const auto& [a, b] = pair;  // const 引用
```

## 限制

- 不能用于嵌套解包：`auto [[a, b], c] = ...` 不合法
- 绑定的变量数量必须与成员数量完全匹配
- 不能忽略某些成员（不像 Python 的 `_`）
