# 索引失效

索引失效指 SQL 语句虽然有可用索引，但优化器无法使用或认为使用索引代价更高，最终走全表扫描或使用低效访问路径。

## 常见原因

1. 对索引列使用函数或表达式：`where left(name, 1) = 'a'`。
2. 隐式类型转换：字符串列用数字比较。
3. 联合索引不满足最左前缀原则。
4. `like '%abc'` 以前缀通配符开头。
5. `or` 两侧并非都能使用索引。
6. 范围查询后面的联合索引列无法继续用于精确匹配。
7. 统计信息不准，优化器估算走索引代价更高。

## 排查方式

1. 使用 `EXPLAIN` 查看访问类型、key、rows、Extra。
2. 检查字段类型和 SQL 字面量类型是否一致。
3. 检查联合索引列顺序是否匹配查询条件。
4. 必要时更新统计信息或重建索引。
