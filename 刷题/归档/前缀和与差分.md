### 前缀和

- 前缀和是指对一个序列的每个元素的前缀元素的和，也就是求出序列中前i个元素的和。
- 例如，对于原数列`a = [1, 2, 3, 4, 5]`，前缀和数组可以为 `sum = [1, 3, 6, 10, 15]`
- 可以使用循环求出前缀和序列：

```C
for (int i = 1; i <= n; i++) {
  sum[i] = sum[i - 1] + a[i - 1];
  //`n` 为原序列的长度，`a` 和 `sum` 分别是原序列和前缀和序列的名称。
}
```

---

前缀和的作用: 快速求出来一段数的和

- `[l,r]`之间所有元素的和： `S[r]-S[l-1]=a1+...+al+...+ar-(a1+...+a[l-1])`

```C
//前缀和
\#include <iostream>
using namespace std;
const int N=100010;
int a[N],s[N];
int n,m;
int main(){
    cin.tie(0);
    cout.tie(0);
    ios::sync_with_stdio(false);

    cin>>n>>m;
    for(int i=0;i<n;i++){
        cin>>a[i];
        s[i+1]=a[i]+s[i];
    }
    for(int i=0;i<m;i++){
        int l,r;
        cin>>l>>r;
        cout<<s[r]-s[l-1]<<endl;
    }
}
//子矩阵的和
//s[i][j]就是，[0][0]到[i][j]矩阵的所有和
\#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int n,m,q;
int a[N][N],s[N][N];
int main(){
    cin.tie(0);
    cout.tie(0);
    ios::sync_with_stdio(0);

    cin>>n>>m>>q;
    for(int i=0;i<n;i++){
        for(int j=0;j<m;j++){
            cin>>a[i][j];
            s[i+1][j+1]=s[i+1][j]+s[i][j+1]+a[i][j]-s[i][j];
        }
    }
    for(int i=0;i<q;i++){
        int x1,y1,x2,y2;
        cin>>x1>>y1>>x2>>y2;
        cout<<s[x2][y2]-s[x2][y1-1]-s[x1-1][y2]+s[x1-1][y1-1]<<endl;
    }
}
```

- [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k)
- 统计数组中连续子数组和为 K 的个数，可以存储所有的前缀和，在每次存储当前前缀和`cnt`的时候判断之前的前缀和有没有值为`cnt-k`，有的话，就存在连续子数组和为K
- 如果要统计和为K的最短子数组，可以采用哈希表来存储(前缀和, 下标)，之后判断哈希表中有没有当前的前缀和- K，如果有的话，判断长度；统计长的话，下标就需要使用左边的下标

- 如果要统计和大于等于K的最短子数组，就不能使用哈希表了。使用单调队列、单调栈

### 差分

- 差分是一种算法，用于将一个序列的元素值变化，转化为一个序列的差分值变化。差分是前缀和的逆运算， 原数组就是差分数组的前缀和
- 差分算法的主要步骤如下：
- 初始化一个数组 `c`，长度为原序列长度加一。
- 遍历原序列，对于每个元素的位置 `x` 和值`v`，将 `c+= v 和 c[x+1] -= v`，以得到差分数组。
- 最后，将差分数组累加求和，得到每个位置的元素值。
- 例如，对于序列`[1, 2, 3, 4, 5]`，差分算法得到的差分数组为 `[1, 1, 1, 1, 1]`，累加求和得到的序列为 `[1, 2, 3, 4, 5]`。

---

- 差分算法常用于区间修改（比如，将`A[l,r]+c`，就可以直接对`B[l]+c、B[r+1]-c` 即可。然后求`B`的前缀和就是`A`），区间查询等问题中，因为它可以将复杂的操作转化为单点修改和前缀查询，提高算法效率

---

```C
//一维差分
\#include <bits/stdc++.h>
using namespace std;
const int N = 100010;
int n,m;
int A[N],B[N];
int main(){
    cin.tie(0);
    cout.tie(0);
    ios::sync_with_stdio(0);

    cin>>n>>m;
    for(int i=1;i<=n;i++){
        cin >> A[i];
        B[i]=A[i]-A[i-1];
    }
    while(m--){
        int l,r,c;
        cin>>l>>r>>c;
        B[l]+=c;
        B[r+1]-=c;
    }
    for(int i=1;i<=n;i++)
        A[i]=B[i]+A[i-1];
    for(int i=1;i<=n;i++)
        cout<<A[i]<<" ";

    return 0;
}

//矩阵差分
\#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int n,m,q;
int a[N][N],b[N][N];

int main(){
    cin.tie(0);
    cout.tie(0);
    ios::sync_with_stdio(0);

    cin>>n>>m>>q;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=m;j++){
            cin>>a[i][j];
            b[i][j]=a[i][j]-a[i][j-1]-a[i-1][j]+a[i-1][j-1];
        }
    }
    while(q--){
        int x1,x2,y1,y2,c;
        cin>>x1>>y1>>x2>>y2>>c;

        b[x1][y1]+=c;
        b[x2+1][y2+1]+=c;

        b[x2+1][y1]-=c;
        b[x1][y2+1]-=c;
    }
    for(int i=1;i<=n;i++)
        for(int j=1;j<=m;j++)
            a[i][j]=a[i][j-1]+a[i-1][j]-a[i-1][j-1]+b[i][j];

    for(int i=1;i<=n;i++){
        for(int j=1;j<=m;j++)
            cout<<a[i][j]<<" " ;
        cout<<endl;
    }

    return 0;
}
```
