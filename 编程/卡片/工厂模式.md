创建型模式。将对象的**创建**和**使用**分离，让调用者不需要知道具体类名。

## 简单工厂（Static Factory）

不属于 GoF 23 种模式，但常见。一个工厂类根据参数决定创建哪种产品。

```cpp
class Shape { public: virtual void draw() = 0; virtual ~Shape() {} };
class Circle : public Shape { public: void draw() override { /* ... */ } };
class Square : public Shape { public: void draw() override { /* ... */ } };

class ShapeFactory {
public:
    static Shape* create(const string& type) {
        if (type == "circle") return new Circle();
        if (type == "square") return new Square();
        return nullptr;
    }
};
```

**缺点**：新增产品需修改工厂类，违反开闭原则。

## 工厂方法（Factory Method）

定义创建对象的接口，由**子类**决定实例化哪个类。稳定点：创建接口；变化点：具体产品。

```cpp
class Logger { public: virtual void log(const string& msg) = 0; virtual ~Logger() {} };
class FileLogger : public Logger { public: void log(const string& msg) override { /* 写文件 */ } };
class DbLogger   : public Logger { public: void log(const string& msg) override { /* 写DB */ } };

class LoggerFactory { public: virtual Logger* create() = 0; virtual ~LoggerFactory() {} };
class FileLoggerFactory : public LoggerFactory { public: Logger* create() override { return new FileLogger(); } };
class DbLoggerFactory   : public LoggerFactory { public: Logger* create() override { return new DbLogger(); } };

// 使用
LoggerFactory* factory = new FileLoggerFactory();
Logger* logger = factory->create();
logger->log("Hello");
```

## 抽象工厂（Abstract Factory）

创建**一族**相关的对象（产品族），适合有多个产品等级结构的场景。

```cpp
// 产品族：按钮 + 文本框（跨平台 UI）
class Button { public: virtual void render() = 0; virtual ~Button() {} };
class TextBox { public: virtual void render() = 0; virtual ~TextBox() {} };

class WinButton : public Button { public: void render() override { /* Win风格 */ } };
class MacButton : public Button { public: void render() override { /* Mac风格 */ } };

class UIFactory {
public:
    virtual Button* createButton() = 0;
    virtual TextBox* createTextBox() = 0;
};
class WinFactory : public UIFactory {
    Button*  createButton()  override { return new WinButton(); }
    TextBox* createTextBox() override { return new WinTextBox(); }
};
```

## 三种工厂对比

| 模式 | 创建对象 | 灵活性 | 适用场景 |
|------|----------|--------|----------|
| 简单工厂 | 一个工厂 | 低 | 产品种类少，变化少 |
| 工厂方法 | 每个产品一个工厂 | 高 | 产品扩展频繁 |
| 抽象工厂 | 产品族工厂 | 高 | 多维度产品族切换 |
