- 堆，默认是大根堆：`priority_queue<int> heap`
- 小根堆：
    - 插入负数
    - 定义成为小根堆 `priority_queue<int,vector<int>,greater> heap;`
    - greater 是小根堆，因为当比较成功，也就是大于根节点的时候会交换，将小值交换到根节点
- push()
- top()
- pop()
- size()
- empty()
- 没有clear函数

---

使用谓词或者仿函数进行更改排序方式或自定义排序方式

- 内置仿函数
- `template<class T> bool equal_to<T>` 等于
- `template<class T> bool not_equal_to<T>` 不等于
- `template<class T> bool greater<T>` **大于**
- `template<class T> bool greater_equal<T>` 大于等于
- `template<class T> bool less<T>` 小于
- `template<class T>bool less_equal<T>`小于等于

- 二元谓词

```C
class MySort{
public:
	bool operator()(int v1, int v2)
		return v1 > v2;
};
```

```C
//默认的sort是调用的less关系仿函数从小到大，改成从大到小
sort(v.begin(),v.end(),MySort());
sort(v.begin(),v.end(),greater<int>());//两种方法一样
```
