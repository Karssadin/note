# <algorithm>

- `min_element(vec.begin(), vec.end());`查找当前范围内最小的元素迭代器
- `max_element(vec.begin(), vec.end());`
- `is_sorted(class first, class last);`检查指定范围内元素是否按照升序排列
- `is_sorted(vec.begin(), vec.end(), greater<int>());`检查指定范围内元素是否按照降序排列
- `sort(v.begin(),v.end());//sort(v.begin(),v.end(),less<int>());`升序排序
- `sort(v.begin(),v.end(),greater<int>());`降序排序
