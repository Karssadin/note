## 刷题中的复杂度估算

根据数据规模快速判断可接受的算法复杂度：

| 数据规模 n | 可接受复杂度 | 典型算法 |
|-----------|-------------|---------|
| n ≤ 20 | O(2ⁿ)、O(n!) | 回溯、状压 DP |
| n ≤ 100 | O(n³) | Floyd、三重循环 DP |
| n ≤ 1000 | O(n²) | 冒泡排序、暴力枚举 |
| n ≤ 10⁵ | O(n log n) | 排序 + 二分、线段树 |
| n ≤ 10⁶ | O(n) | 双指针、前缀和 |
| n ≤ 10⁸ | O(log n)、O(1) | 二分查找、数学公式 |

一般 OJ 每秒可执行约 10⁸ 次基础运算，以此估算时间限制是否可行。
