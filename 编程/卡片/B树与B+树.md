# B树与B+树

B 树和 B+ 树都是多路平衡搜索树，核心目标是降低树高，从而减少磁盘或页访问次数。

## B 树

1. 每个节点既保存 key，也保存数据或数据指针。
2. 查询可能在非叶子节点命中。
3. 范围查询需要中序遍历，顺序访问能力较弱。

## B+ 树

1. 非叶子节点只保存 key 和子节点指针。
2. 数据都保存在叶子节点。
3. 叶子节点通常通过链表相连，适合范围查询。
4. 非叶子节点能容纳更多 key，树高更低。

## 为什么数据库索引常用 B+ 树

1. 磁盘页利用率高，减少随机 IO。
2. 范围查询可沿叶子链表顺序扫描。
3. 所有查询最终到叶子节点，访问路径更稳定。
4. 相比红黑树，B+ 树更适合块设备和页式存储。
