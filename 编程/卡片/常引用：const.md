## 常引用（const reference）

常引用是对 `const` 修饰的引用，用于绑定不可修改的对象或值。

```cpp
const int a = 10;
const int& ref = a;   // 正确：常引用绑定常量
// ref = 20;          // 错误：不能通过常引用修改值
```

## 常量左值引用绑定右值

`const` 引用可以绑定**右值**（临时对象）和**不同类型**的对象（只要类型可转换），这是普通引用做不到的：

```cpp
const int& r1 = 42;          // OK：绑定字面量（临时量）
const double& r2 = 10;       // OK：int 隐式转换为 double 临时量
// int& r3 = 42;             // 错误：非常量引用不能绑定右值
```

这一特性使得函数参数常用 `const T&`：
- 既能接受左值，也能接受右值（临时对象）
- 避免不必要的拷贝

## 与 `const int* const` 的关系

从底层看，常引用相当于 `const int* const p = &a`：
- `*p`（所指内容）被 const 修饰，不可修改
- `p`（指针本身）被 const 修饰，不可改变指向

即**常引用的指向和所指内容均不可变**。

## 用途

1. **函数参数**：`void func(const std::string& s)` — 高效传参，避免拷贝
2. **返回值**：返回 `const T&` 避免拷贝，同时禁止外部修改
3. **延长临时对象生命周期**：`const Foo& f = createFoo();` — 生命周期延长到引用作用域结束

## 与普通引用的区别

| 特性 | 引用（`T&`） | 常引用（`const T&`） |
|------|------------|-------------------|
| 能否修改所指对象 | 能 | 不能 |
| 能否绑定右值/临时量 | 不能 | 能 |
| 能否绑定不同类型 | 不能 | 能（隐式转换） |
| 常用场景 | 输出参数 | 只读输入参数 |
