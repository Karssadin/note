# 异常处理

```cpp
try {
    throw std::runtime_error("error msg");
} catch (const std::runtime_error& e) {
    std::cerr << e.what();
} catch (...) { }
```

1. 异常抛出 `throw`：可以抛出任意类型，标准库异常继承自 `std::exception`
2. 异常捕获 `catch`：按类型匹配，从上到下，`catch(...)` 兜底
3. 异常安全级别：
	- **基本保证**：异常后对象仍处于有效状态
	- **强保证**：异常后状态回滚到调用前（copy-and-swap 手法）
	- **不抛出保证**：保证不抛异常（标记 [[noexcept]]）
