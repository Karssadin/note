1. 一维数组

- 定义方式
- 一定要有一个初始长度或者后面中括号有值

```C++
//1、数组类型 数组名[数组长度];
int a[5];
//2、数组类型 数组名[数组长度]={值，值……}；
//使用这种方法时候如果没有全部指定初始化值，就会赋值为0，所以可以使用int a[5]={0}直接全部赋值为0
int a[5]={1,2,3,4,5};
//3、数组类型 数组名[]={值……};推测元素个数
int a[]={1,2,3,4,5};
```

- 数组名
- 数组名为对应的数组在内存中的首地址
- 通过sizeof(数组名)可以获取数组占据内存的长度；

```C
int len =sizeof(arr)/sizeof(arr[0]);
```

- a[5]，代表的是从起始地址a+5的地址，+5其中的5是元素类型所占空间大小*5

数组元素逆置：使用双指针

```C
int start=0;
int end=sizeof(arr)/sizeof(arr[0])-1;
while(end>start){
	int tmp=arr[end];
	arr[end]=arr[start];
	arr[start]=tmp;
	++end;
	--start;
}
```

- 一维数组冒泡排序

1. 比较相邻的元素。如果第一个比第二个大，就交换他们两个
2. 对每一对相邻元素作同样的工作，从开始第一对到结尾的最后一对。这步做完后，最后的元素会是最大的数
3. 针对所有的元素重复以上的步骤，除了最后一个（最外层只需要n-1层就行）

- 持续每次对越来越少的元素重复上面的步骤，直到没有任何一对数字需要比较(设置flag，当某次循环没有交换时候就直接break最外层循环)

```C++
void bubble(){
	int arr[5]={9,1,3,55,2};
	int len =sizeof(arr)/sizeof(arr[0]);
	for(int i=0;i<len -1;i++){
		int flag=0;
		for(int j=0;j<len-i-1;j++){
			if(arr[j]>arr[j+1]){
				int tmp=arr[j+1];
				arr[j+1]=arr[j];
				arr[j]=tmp;
				flag=1;
			}
			if(flag==0)
				break;
		}
	}
}
```

1. 二维数组

> **一维数组的数组**

- 定义方式

```C++
//数据类型 数组名[行数][列数];
int a[2][3];//2行3列
//数据类型 数组名[行数][列数]={{值……}，{值……}};
int a[2][3]={{1，2,2}，{3，4,2}};
//数据类型 数组名[行数][列数]={值……}
int a[2][2]={1,2,3,4};
//数据类型 数组名[][列数]={值……};
int a[][2]={1,2,3,4};
```

建议使用第二种

- 数组名
    - 查看数组所占内存空间
    - 查看二维数组首地址
    - 计算二维数组元素数
