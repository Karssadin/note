**IPC（Inter-Process Communication）**：进程间通信，指不同进程之间传递或交换信息的机制。

进程间**地址空间相互独立**，不能直接访问对方内存，必须借助 OS 提供的 IPC 机制。

## IPC 方式对比

| 机制 | 同机器 | 跨网络 | 速度 | 持久性 | 典型场景 |
|------|--------|--------|------|--------|---------|
| **管道（Pipe）** | ✅ | ❌ | 快 | 随进程消亡 | 父子进程单向通信 |
| **命名管道（FIFO）** | ✅ | ❌ | 快 | 持久到手动删除 | 无亲缘关系进程 |
| **消息队列** | ✅ | ❌ | 中 | 持久到删除/重启 | 异步消息传递 |
| **信号量** | ✅ | ❌ | 很快 | 持久到删除/重启 | 进程同步/互斥 |
| **共享内存** | ✅ | ❌ | **最快** | 持久到删除/重启 | 大量数据传输 |
| **信号** | ✅ | ❌ | - | - | 事件通知 |
| **Socket** | ✅ | ✅ | 较慢 | 连接断开消亡 | 网络通信、本地服务 |

## 1. 管道（Pipe）

无名管道：单向、父子进程间通信。

```cpp
#include <unistd.h>
int fd[2];
pipe(fd);   // fd[0] 读端，fd[1] 写端

if (fork() == 0) {         // 子进程
    close(fd[0]);          // 关闭读端
    write(fd[1], "hello", 5);
} else {                   // 父进程
    close(fd[1]);          // 关闭写端
    char buf[10];
    read(fd[0], buf, 10);  // 读取子进程写入的数据
}
```

**特点**：
- 数据流是单向的（`fd[1]` 写 → `fd[0]` 读）
- 只能在有亲缘关系的进程间使用（继承 fd）
- 容量有限（Linux 默认 64KB），写满阻塞

## 2. 命名管道（FIFO）

```bash
mkfifo /tmp/myfifo   # 创建命名管道
```

```cpp
// 进程1（写）
int fd = open("/tmp/myfifo", O_WRONLY);
write(fd, "hello", 5);

// 进程2（读）
int fd = open("/tmp/myfifo", O_RDONLY);
char buf[10];
read(fd, buf, 10);
```

**优点**：无需亲缘关系，以文件路径为标识。

## 3. 消息队列（Message Queue）

内核维护的**有序消息链表**，按消息类型（mtype）分类。

```cpp
#include <sys/msg.h>

struct msgbuf { long mtype; char mtext[256]; };
int msgid = msgget(IPC_PRIVATE, 0666 | IPC_CREAT);

// 发送消息
struct msgbuf msg = {1, "hello"};
msgsnd(msgid, &msg, strlen(msg.mtext), 0);

// 接收指定类型的消息
struct msgbuf recv;
msgrcv(msgid, &recv, sizeof(recv.mtext), 1, 0);
```

**优点**：可按类型选择接收，持久化（进程退出后消息仍在）。

## 4. 信号量（Semaphore）

用于**进程间同步/互斥**，而非数据传输。

```cpp
#include <semaphore.h>

// POSIX 有名信号量（跨进程）
sem_t* sem = sem_open("/mysem", O_CREAT, 0644, 1);  // 初始值 1（互斥量）
sem_wait(sem);   // P 操作（减1，0时阻塞）
// ... 临界区 ...
sem_post(sem);   // V 操作（加1，唤醒等待者）
sem_close(sem);
sem_unlink("/mysem");
```

**与互斥锁的区别**：信号量可跨进程，互斥锁通常只在线程间使用（pthread_mutex）。

## 5. 共享内存（Shared Memory）

**最快的 IPC 方式**：多个进程映射同一块物理内存，直接读写无需数据拷贝。

```cpp
#include <sys/shm.h>
// System V 共享内存
int shmid = shmget(IPC_PRIVATE, 4096, 0666 | IPC_CREAT);
char* shm = (char*)shmat(shmid, nullptr, 0);   // 附加
strcpy(shm, "hello from process1");
shmdt(shm);          // 分离
shmctl(shmid, IPC_RMID, nullptr);  // 删除

// POSIX mmap 方式（更推荐）
int fd = shm_open("/myshm", O_CREAT | O_RDWR, 0666);
ftruncate(fd, 4096);
void* ptr = mmap(nullptr, 4096, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
```

**注意**：共享内存本身不提供同步，需配合信号量/互斥锁使用。

## 6. Socket（套接字）

**唯一支持跨网络的 IPC 方式**。本地通信也可使用 Unix Domain Socket（性能优于 TCP）：

```cpp
// Unix Domain Socket（本地高速通信）
int sock = socket(AF_UNIX, SOCK_STREAM, 0);
struct sockaddr_un addr;
addr.sun_family = AF_UNIX;
strcpy(addr.sun_path, "/tmp/mysock");
```

详见 [[Socket编程]]。

## 选择建议

- **父子进程**、单向数据流 → 管道
- **无亲缘进程**、少量数据 → 命名管道 / 消息队列
- **大量数据**、高性能 → 共享内存（+信号量同步）
- **进程同步** → 信号量
- **事件通知** → 信号（简单）/ 条件变量（复杂）
- **跨网络** → Socket；**本地高性能** → Unix Domain Socket
