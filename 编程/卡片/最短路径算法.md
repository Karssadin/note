## 最短路径算法总览

| 算法 | 适用场景 | 权重 | 时间复杂度 | 多源/单源 |
|------|---------|------|-----------|---------|
| BFS | 无权图 | 无权 | O(V+E) | 单源 |
| Dijkstra | 非负权图 | 非负 | O((V+E)logV) | 单源 |
| Bellman-Ford | 含负权图 | 可负 | O(VE) | 单源，可检测负环 |
| SPFA | Bellman-Ford 优化 | 可负 | O(kE) 均摊 | 单源（竞赛常用）|
| Floyd-Warshall | 任意两点间 | 可负（无负环）| O(V³) | 多源 |

## Dijkstra 算法（最常考）

**核心思想**：贪心策略——每次从未确定集合中选距离最小的节点，更新其邻居距离。

**条件**：边权必须为非负

```cpp
#include <queue>
#include <vector>
#include <climits>
using namespace std;

// adj[u] = {v, weight}
vector<int> dijkstra(int start, int n, vector<vector<pair<int,int>>>& adj) {
    vector<int> dist(n, INT_MAX);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;

    dist[start] = 0;
    pq.push({0, start});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;  // 过期节点，跳过

        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
```

- 使用**小顶堆（优先队列）**实现：O((V+E)logV)
- 不能处理负权边（贪心策略失效）

## Bellman-Ford 算法

**核心思想**：对所有边进行 V-1 次松弛操作。

**条件**：可以有负权边，能检测负权环（第 V 次仍能松弛则存在负环）

```cpp
vector<int> bellmanFord(int start, int n, vector<tuple<int,int,int>>& edges) {
    // edges: (u, v, weight)
    vector<int> dist(n, INT_MAX);
    dist[start] = 0;

    for (int i = 0; i < n - 1; i++) {  // V-1 轮松弛
        for (auto [u, v, w] : edges) {
            if (dist[u] != INT_MAX && dist[u] + w < dist[v])
                dist[v] = dist[u] + w;
        }
    }

    // 检测负权环
    for (auto [u, v, w] : edges) {
        if (dist[u] != INT_MAX && dist[u] + w < dist[v])
            return {};  // 存在负权环
    }
    return dist;
}
```

- 时间复杂度 O(VE)，较慢
- **SPFA**（Shortest Path Faster Algorithm）是其队列优化版本，均摊 O(kE)

## Floyd-Warshall 算法（全源最短路）

**核心思想**：动态规划，`dp[i][j][k]` = 仅经过 0..k 节点时，i 到 j 的最短路。

```cpp
void floydWarshall(vector<vector<int>>& dist, int n) {
    // dist[i][j] 初始为边权，无边则 INF，dist[i][i]=0
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (dist[i][k] != INT_MAX && dist[k][j] != INT_MAX)
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
}
```

- O(V³)，适合 V ≤ 500 的稠密图
- 对角线出现负值，说明存在负环

## 算法选择指南

```
需要多源最短路 → Floyd-Warshall
↓
单源，有负权？
  有负环检测需求 → Bellman-Ford
  仅求最短路 → SPFA
  无负权 → Dijkstra（优先队列）
  无权图 → BFS
```
