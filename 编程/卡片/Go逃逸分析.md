# Go逃逸分析

逃逸分析用于判断变量是否可以分配在栈上，还是必须逃逸到堆上。

## 常见逃逸原因

1. 返回局部变量地址。
2. 变量被接口装箱后生命周期不明确。
3. 闭包捕获外部变量。
4. 对象过大或编译器无法证明生命周期。
5. 指针被保存到堆对象中。

## 查看方式

```bash
go build -gcflags="-m" ./...
```

## 影响

1. 堆分配增加 GC 压力。
2. 栈分配通常更快，函数返回后即可释放。
3. 优化重点是减少热点路径上的不必要分配。
