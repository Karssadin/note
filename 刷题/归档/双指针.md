- [26. 删除有序数组中的重复项](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/description/)
- 保留 k 个相同数字，对于前 k 个数字，我们可以直接保留。
- 对于后面的任意数字，能够保留的前提是：与当前写入的位置前面的第 k 个元素进行比较，不相同则保留。

```C
class Solution {
public:
int removeDuplicates(vector<int>& nums) {
        return process(nums, 1);
    }
    int process(vector<int>& nums,int k){
        int idx = 0;
        //idx是当前填充的索引
        for(auto x : nums){
            // 前K个值直接写入
            //之后就需要判断idx - k之前是不是跟现在要写入的相等，如果不相等再写入
            if(idx < k || nums[idx - k] != x){
                nums[idx++] = x;
            }
        }
        return idx;
    }
};
```

- [844.比较含退格的字符串](https://leetcode.cn/problems/backspace-string-compare/)
- 重构字符串
- 1：使用两个新的字符串来存储删除退格之后的字符串，遇到退格就让当前新字符串的索引 - 1，之后进行比较两个新字符串；
- 2： 使用栈来存储新字符串，碰到退格就pop，之后返回
- 双指针
- 定义 skip 表示当前待删除的字符的数量。
- 遍历到一个字符：若该字符为退格符，skip + 1
- 若该字符为普通字符：若skip = 0则说明当前字符不需要删去；
- 若skip不为 0，则说明当前字符需要删去，skip - 1
- 定义两个指针，分别指向两字符串的末尾。让两指针逆序地遍历两字符串，直到两字符串能够各自确定一个字符，然后将这两个字符进行比较。重复这一过程直到找到的两个字符不相等，或遍历完字符串为止。
