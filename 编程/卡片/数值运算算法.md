`<numeric>` 头文件中的数值运算算法（accumulate 见独立卡片）。

## iota

填充递增序列：

```cpp
vector<int> v(5);
iota(v.begin(), v.end(), 0);   // v = {0, 1, 2, 3, 4}
iota(v.begin(), v.end(), 10);  // v = {10, 11, 12, 13, 14}
```

## partial_sum（前缀和）

```cpp
vector<int> v = {1, 2, 3, 4, 5};
vector<int> ps(5);
partial_sum(v.begin(), v.end(), ps.begin());
// ps = {1, 3, 6, 10, 15}
```

## adjacent_difference（相邻差分）

前缀和的逆运算：

```cpp
vector<int> v = {1, 3, 6, 10, 15};
vector<int> d(5);
adjacent_difference(v.begin(), v.end(), d.begin());
// d = {1, 2, 3, 4, 5}
```

## inner_product（内积）

两个序列对应元素相乘后求和：

```cpp
vector<int> a = {1, 2, 3};
vector<int> b = {4, 5, 6};
int result = inner_product(a.begin(), a.end(), b.begin(), 0);
// 1*4 + 2*5 + 3*6 = 32
```

## C++17 并行算法

| 算法 | 说明 |
|------|------|
| `reduce` | 并行友好的 accumulate（要求操作满足交换律+结合律） |
| `transform_reduce` | map-reduce 模式：先变换再归约 |
| `inclusive_scan` | 并行友好的 partial_sum |
| `exclusive_scan` | 不含当前元素的前缀和 |

```cpp
// 需要 <numeric> 和 <execution>
int sum = reduce(execution::par, v.begin(), v.end(), 0);
```
