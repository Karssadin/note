# Go垃圾回收

Go 使用并发三色标记清扫 GC，并通过写屏障保证并发标记期间对象图的一致性。

## 基本过程

1. 标记准备：短暂停顿，开启写屏障。
2. 并发标记：GC 与用户 goroutine 并发执行。
3. 标记终止：短暂停顿，完成标记收尾。
4. 清扫：回收不可达对象占用的内存。

## 三色标记

1. 白色：尚未访问，标记结束后仍为白色则可回收。
2. 灰色：已发现但子对象未全部扫描。
3. 黑色：自身和子对象都已扫描。

## 调优方向

1. 减少分配频率。
2. 控制对象生命周期。
3. 用 `GOGC` 调整 GC 触发比例。
4. 通过 pprof 观察堆分配和保留对象。
