# 事务与并发控制

## 主要内容

1. 事务基本概念和 ACID。
2. 并发异常与隔离级别。
3. 锁机制、MVCC、乐观并发控制和悲观并发控制。
4. 分布式事务中的 2PC、3PC 和一致性协议。

### 事务的基本概念

- ACID 特性
- 事务的生命周期与状态
- CAP 定理与 BASE 理论

### 并发控制

- 锁机制：排他锁与共享锁
- 二阶段锁（2PL）与多版本控制（MVCC）
- 乐观并发控制与悲观并发控制

### 分布式事务

- 两阶段提交（2PC）
- 三阶段提交（3PC）
- 分布式锁与全局一致性（如 Paxos、Raft）
