# Go与C++对比

Go 和 C++ 都常用于系统和服务端开发，但语言目标和工程取舍明显不同。

| 维度 | Go | C++ |
|------|----|-----|
| 内存管理 | GC 自动回收 | 手动管理、RAII、智能指针 |
| 并发 | goroutine、channel、sync | thread、future、mutex、协程 |
| 泛型 | 类型参数，能力相对克制 | 模板系统强大，编译期能力强 |
| 面向对象 | 结构体、接口、组合 | class、继承、多态 |
| 工具链 | gofmt、go test、go mod 统一 | 工具链和构建系统选择更多 |
| 性能控制 | runtime 参与更多 | 更接近底层，控制粒度更细 |

## 选择倾向

1. 网络服务、基础设施工具、并发 IO：Go 通常开发效率高。
2. 极致性能、底层库、复杂泛型抽象：C++ 更有优势。
