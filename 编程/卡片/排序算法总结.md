## 排序算法对比

| 算法 | 平均 | 最好 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|------|
| [[冒泡排序]] | O(n²) | O(n) | O(n²) | O(1) | 稳定 |
| [[选择排序]] | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| [[插入排序]] | O(n²) | O(n) | O(n²) | O(1) | 稳定 |
| [[希尔排序]] | O(n^1.3) | O(n) | O(n²) | O(1) | 不稳定 |
| [[快速排序]] | O(n log n) | O(n log n) | O(n²) | O(log n) | 不稳定 |
| [[归并排序]] | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| [[堆排序]] | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| [[计数排序]] | O(n+k) | O(n+k) | O(n+k) | O(k) | 稳定 |
| [[桶排序与基数排序\|桶排序]] | O(n+k) | O(n) | O(n²) | O(n+k) | 稳定 |
| [[桶排序与基数排序\|基数排序]] | O(d·(n+k)) | O(d·(n+k)) | O(d·(n+k)) | O(n+k) | 稳定 |

> k 为数据范围，d 为最大位数

## 分类

**比较排序**（理论下界 O(n log n)）：冒泡、选择、插入、希尔、快排、归并、堆排序

**非比较排序**（可突破 O(n log n)）：计数排序、桶排序、基数排序

## 选择建议

| 场景 | 推荐算法 |
|------|----------|
| 数据量小（n < 50） | 插入排序 |
| 数据基本有序 | 插入排序、冒泡排序 |
| 通用场景 | 快速排序（实践最快） |
| 要求稳定 | 归并排序 |
| 内存受限 | 堆排序（O(1) 额外空间） |
| 数据范围已知且较小 | 计数排序 |
| 外部排序（磁盘） | 归并排序 |
| 链表排序 | 归并排序（无需随机访问） |

## 稳定性

稳定排序保证**相等元素的相对顺序不变**。需要稳定性的场景：多关键字排序（先按成绩排，再按姓名排，要求成绩相同时保持姓名顺序）。
