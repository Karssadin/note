# Go类型断言与方法集

Go 的接口是否被某个类型实现，取决于该类型的方法集。类型断言用于从接口值中取回具体类型或判断是否满足另一个接口。

## 方法集

1. 类型 `T` 的方法集包含接收者为 `T` 的方法。
2. 类型 `*T` 的方法集包含接收者为 `T` 和 `*T` 的方法。
3. 如果接口要求的方法包含指针接收者，通常只有 `*T` 满足接口。
4. 值接收者适合不可变、小对象；指针接收者适合修改对象或避免拷贝。

## 类型断言

```go
v, ok := x.(io.Reader)
if !ok {
	return
}
```

1. `v := x.(T)` 断言失败会 panic。
2. `v, ok := x.(T)` 可以安全判断。
3. type switch 适合对多个动态类型分支处理。

```go
switch v := x.(type) {
case string:
	_ = v
case []byte:
	_ = v
}
```
