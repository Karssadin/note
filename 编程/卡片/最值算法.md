`<algorithm>` 中的最值相关算法。

## min / max

返回两个值中的较小/较大值：

```cpp
int a = min(3, 5);           // 3
int b = max(3, 5);           // 5
int c = min({3, 1, 4, 1, 5}); // 1（initializer_list 版本）
```

## min_element / max_element

返回序列中最小/最大元素的**迭代器**：

```cpp
auto it = min_element(v.begin(), v.end());
int minVal = *it;
int minIdx = it - v.begin();

// 自定义比较
auto it2 = max_element(v.begin(), v.end(),
    [](const auto& a, const auto& b){ return a.score < b.score; });
```

## minmax / minmax_element

同时返回最小值和最大值的 pair，比分别调用 min/max 少一半比较次数：

```cpp
auto [lo, hi] = minmax({3, 1, 4, 1, 5});    // lo=1, hi=5
auto [minIt, maxIt] = minmax_element(v.begin(), v.end());
```

## clamp（C++17）

将值限制在 `[lo, hi]` 范围内：

```cpp
int x = clamp(15, 0, 10);   // 10（超过上限，截断为 10）
int y = clamp(-5, 0, 10);   // 0（低于下限，截断为 0）
int z = clamp(5, 0, 10);    // 5（在范围内，不变）
```
