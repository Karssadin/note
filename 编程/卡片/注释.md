C/C++ 中三种注释方式：

- **单行注释** `//`：从 `//` 到行尾，C99/C++ 标准
- **多行注释** `/* */`：可跨行，不可嵌套
- **条件编译注释** `#if 0`：可嵌套，常用于临时屏蔽大段代码

```cpp
// 单行注释

/*
 * 多行注释
 * 不能嵌套 /* 这样会出错 */
 */

#if 0
    // 条件编译注释，可以包含 /* */ 不受影响
    // 常用于临时禁用一段代码
    some_function();
#endif
```

注释原则：解释**为什么**（Why），而非**做了什么**（What）。好代码本身说明 What。
