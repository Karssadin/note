- 翻转字符串里面的单词：移除多余空格、将整个字符串翻转、将每个单词翻转
- 移除多余空格，可以参考使用双指针移除元素的题

```C
//移除多余空格
void remoeExtraSpaces(string& s){
    int slow = 0;
    for(int i = 0; i < s.size(); ++i){
        if(s[i] != ' '){
            if(slow != 0)
                s[slow++] = ' ';
            while(i < s.size() && s[i] != '')
                s[slow++] = s[i++];
        }
    }
    s.resize(slow);
}
```
