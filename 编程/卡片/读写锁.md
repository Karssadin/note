- 读写锁允许多个线程同时读共享资源，但只允许一个线程写入。这意味着如果没有线程写入，多个线程可以并行读取。这提高了并发性。
- 优点：提高读取的并发性，因为读操作通常比写操作更频繁。

## Go 使用

Go 中读写锁由 `sync.RWMutex` 提供：

```go
var rw sync.RWMutex
var cache map[string]string

func get(key string) string {
	rw.RLock()
	defer rw.RUnlock()
	return cache[key]
}

func set(key, value string) {
	rw.Lock()
	defer rw.Unlock()
	cache[key] = value
}
```

## 注意

1. 读锁之间可以并发，写锁会排斥所有读写操作。
2. 适合读多写少场景；写多时可能不如普通 [[互斥锁]]。
3. 不要在持有读锁时直接升级为写锁，容易造成死锁。
