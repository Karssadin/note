### 设置桌面快捷方式
> 以clash为例
```Plain

[Desktop Entry]

Name=clash
GenericName=clash
Exec="/home/ksd/clash/cfw" %f
Icon=/home/ksd/clash/1.png
Terminal=clash

Categories=Network;
```

```Plain

sh -c "$(wget <https://raw.github.com/robbyrussell/oh-my-zsh/master/tools/install.sh> -O -)"
```

- oh-my-zsh的插件路径：`~/.oh-my-zsh/plugins`
- zsh的配置文件:`~/.zshrc`

在该配置文件中plugins添加自己想要的插件即可(或者在上述配置文件中添加source 对应插件的.zsh文件)，有些需要在git下载  
如果要在plugins中使用对应插件的话，命名规范：插件.plugins.zsh  

- [主题](https://github.com/robbyrussell/oh-my-zsh/wiki/Themes)
- 在配置文件中的ZSH_THEME替换即可，random为随机
- 安装插件

```Shell
cd ~/.oh-my-zsh/plugins
git clone git://github.com/zsh-users/zsh-syntax-highlighting.git

cd ~/.oh-my-zsh/plugins
git clone git://github.com/zsh-users/zsh-autosuggestions
```

- 配置history

```Shell
# 配置文件中添加如下
# History in cache directory:
HISTSIZE=10000
SAVEHIST=10000
HISTFILE=~/.cache/zsh/history


# 添加文件
mkdir -p ~/.cache/zsh
touch ~/.cache/zsh/history
```

#### 远程连接wsl虚拟机
- 安装wsl之后使用远程连接wsl内虚拟机
- 这里设置的是NAT模式
- 安装完成之后，测试能否互相ping通
- 能互相ping通之后，将ssh的端口做一个映射，在wsl中使用ifconfig查找ip
```
netsh interface portproxy add v4tov4 listenport=8989 listenaddress=0.0.0.0 connectport=8989 connectaddress=<wsl_ip>

#检查是否成功
netsh interface portproxy show all

#将主机的防火墙8989端口打开
netsh advfirewall firewall add rule name="WSL2" dir=in action=allow protocol=TCP localport=8989
```
- 另一台可以ping通主机的电脑就可以通过ssh wsl_用户名@主机ip -p 8989连接到wsl了
