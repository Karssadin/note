# Go结构体

Go 结构体用于把多个字段组合成一个自定义类型，是 Go 表达对象和数据模型的主要方式。

```go
type User struct {
	ID   int
	Name string
}
```

## 特点

1. 结构体是值类型，赋值会拷贝所有字段。
2. 字段名首字母大写表示可导出。
3. 可以通过匿名字段实现嵌入和组合。
4. 结构体 tag 常用于 JSON、ORM、校验等反射场景。
5. 字段顺序会影响内存对齐和结构体大小。
