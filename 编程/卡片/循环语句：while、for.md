- 判断条件是否满足，循环执行相应语句，直到跳出循环条件满足

**break; 退出当前层循环**

|循环类型|描述|
|---|---|
|while|在给定条件为真时重复语句或语句组。 它在执行循环体之前测试条件。|
|for|多次执行一系列语句，并缩写管理循环变量的代码。|
|do... while|像while语句一样，除了它测试循环体末端的条件。|
|嵌套循环|可以嵌套循环，在循环里面再嵌套一层循环|
|无限循环|条件永远不会变为假，则循环变为无限循环， **for**循环传统上用于此目的：**for( ; ; )**|

- while

```C
/*
while(循环条件){
循环语句;
}
*/
```

- do……while

```C
/*
do{
循环语句；
}while(循环条件)；
先执行一次，再判断条件
*/
```

- for

```C
//for(起始表达式;条件表达式;末尾循环体){循环语句}
```

### 循环控制语句

|语句|描述|
|---|---|
|break|跳出选择或者循环、switch|
|continue|在本次循环中跳过本次循环中尚未执行语句，执行下次循环|
|goto|无条件跳转语句，跳转到带标签的语句，不怎么常用|
