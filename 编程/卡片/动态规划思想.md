## 核心思想

将原问题拆解为**重叠子问题**，通过存储子问题的解避免重复计算。适用条件：

1. **最优子结构**：问题的最优解包含子问题的最优解
2. **重叠子问题**：不同状态的计算依赖相同的子问题

## 解题框架

1. **定义状态**：`dp[i]` 代表什么
2. **推导转移方程**：`dp[i]` 和 `dp[i-1]`、`dp[i-2]` 等的关系
3. **初始化**：base case
4. **确定遍历顺序**：确保计算 `dp[i]` 时所需的子问题已经求解
5. **验证**：用小规模数据手动推导

## 实现方式

### 自顶向下（记忆化搜索）

```cpp
unordered_map<int, int> memo;
int fib(int n) {
    if (n <= 1) return n;
    if (memo.count(n)) return memo[n];
    return memo[n] = fib(n - 1) + fib(n - 2);
}
```

### 自底向上（递推表）

```cpp
int fib(int n) {
    if (n <= 1) return n;
    vector<int> dp(n + 1);
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++)
        dp[i] = dp[i - 1] + dp[i - 2];
    return dp[n];
}
```

### 空间优化（滚动变量）

当 `dp[i]` 只依赖前几个状态时，可用变量代替数组：

```cpp
int fib(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int c = a + b;
        a = b; b = c;
    }
    return b;
}
```

## 经典问题分类

| 类型 | 示例 |
|------|------|
| 线性 DP | 最长递增子序列 (LIS)、最大子数组和 |
| 区间 DP | 矩阵链乘法、戳气球 |
| 背包 DP | 0-1 背包、完全背包、多重背包 |
| 树形 DP | 树的最大路径和、打家劫舍 III |
| 状压 DP | 旅行商问题 (TSP) |
| 数位 DP | 统计特定数字出现次数 |

## DP vs 贪心

| 维度 | 动态规划 | 贪心 |
|------|----------|------|
| 决策方式 | 综合所有子问题 | 每步局部最优 |
| 正确性 | 一定最优 | 需证明局部最优→全局最优 |
| 复杂度 | 通常更高 | 通常更低 |
| 适用 | 重叠子问题 + 最优子结构 | 贪心选择性质 |
