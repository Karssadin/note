- 友元提供了不同类的成员函数之间、类的成员函数与一般函数之间进行数据共享的机制。通过友元，一个不同函数或另一个类中的成员函数可以访问类中的私有成员和保护成员。
    - 普通函数定义为友元函数，使普通函数能够访问类的私有成员。
    - 全局函数：在类中进行声明一下全局函数，最前面添加friend关键字
    - 友元类：类之间共享数据。在当前类中声名一下友元类

```C++
//友元函数
class MyClass {
private:
    int secretValue;
public:
    MyClass(int value) : secretValue(value) {}

    friend void showSecret(const MyClass& obj);
};

void showSecret(const MyClass& obj) {
    std::cout << "Secret value: " << obj.secretValue << std::endl;
}
//友元类
class FriendClass;

class MyClass {
private:
    int secretValue;

public:
    MyClass(int value) : secretValue(value) {}

    friend class FriendClass;
};
class FriendClass {
public:
    void showSecret(const MyClass& obj) {
        std::cout << "Secret value: " << obj.secretValue << std::endl;
    }
};
```
