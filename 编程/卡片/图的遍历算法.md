## 深度优先搜索（DFS）

沿一条路径尽可能深入，遇到死路回溯。使用**栈**（递归调用栈或显式栈）实现。

### 邻接表 DFS

```cpp
vector<vector<int>> adj;
vector<bool> visited;

void dfs(int u) {
    visited[u] = true;
    for (int v : adj[u]) {
        if (!visited[v])
            dfs(v);
    }
}
```

### 应用场景

- 连通分量检测
- 拓扑排序（后序 + 逆序）
- 环检测（记录递归栈状态）
- 路径搜索、回溯问题

## 广度优先搜索（BFS）

逐层扩展，使用**队列**实现。天然适合求**最短路径**（无权图）。

### 邻接表 BFS

```cpp
void bfs(int start) {
    queue<int> q;
    vector<bool> visited(adj.size(), false);
    vector<int> dist(adj.size(), -1);

    visited[start] = true;
    dist[start] = 0;
    q.push(start);

    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
}
```

### 应用场景

- 无权图最短路径
- 层序遍历
- 多源 BFS（如腐烂的橘子）
- 双向 BFS 加速搜索

## DFS vs BFS

| 维度 | DFS | BFS |
|------|-----|-----|
| 数据结构 | 栈（递归/显式） | 队列 |
| 空间复杂度 | O(h)，h 为深度 | O(w)，w 为最大宽度 |
| 最短路径 | 不保证 | 保证（无权图） |
| 适用场景 | 路径搜索、回溯、拓扑排序 | 最短路径、层序处理 |
| 实现难度 | 递归简洁 | 迭代为主 |

## 图的存储方式

| 存储方式 | 空间 | 适用场景 |
|----------|------|----------|
| 邻接矩阵 | O(V²) | 稠密图、快速判断边是否存在 |
| 邻接表 | O(V+E) | 稀疏图、遍历邻居 |
| 链式前向星 | O(V+E) | 竞赛中常用，内存紧凑 |
