- [55. 跳跃游戏](https://leetcode.cn/problems/jump-game/)
- 每次取最大覆盖范围，如果覆盖范围中有终点就说明可以跳到终点
- 遍历的时候 索引小于等于cover，不能跳过去的就无法过去

```C
bool canJump(vector<int>& nums) {
    int cover = 0;
    if (nums.size() == 1) return true; // 只有一个元素，就是能达到
    for (int i = 0; i <= cover; i++) { // 注意这里是小于等于cover
        cover = max(i + nums[i], cover);
        if (cover >= nums.size() - 1) return true; // 说明可以覆盖到终点了
    }
    return false;
}
```

- [45. 跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/)
- 如果下标遇到了当前最远覆盖距离下标，步数 + 1，更新当前最远覆盖距离下标
- 只需要遍历到nums.size() - 2，因为如果下标遇到了当前最远覆盖距离下标，再走一步就可以到终点，ans++。或者是，下标不等于当前最远覆盖距离下标，就说明最远覆盖距离可以到达终点，不需要再走一步

```C
int jump(vector<int>& nums) {
    int res = 0;
    int curDis = 0;//下一步覆盖的最远距离下标
    int nextDis = 0;// 当前跳跃能到的最远距离下标
    int cover = 0;
    for(int i = 0; i < nums.size() - 1; i++){
        nextDis = max(nums[i] + i, nextDis);
        if(i == curDis){
            curDis = nextDis;
            res++;
        }
    }
    return res;
}
```
