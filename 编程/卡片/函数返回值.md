C++ 函数返回值的类型、传递方式和注意事项。

## 返回方式

```cpp
int getValue();              // 返回值（拷贝）
int& getRef();               // 返回引用（避免拷贝，注意生命周期）
const int& getConstRef();    // 返回 const 引用
int* getPtr();               // 返回指针
```

## 不要返回局部变量的引用或指针

```cpp
int& bad() {
    int x = 42;
    return x;  // 危险：x 在函数返回后销毁，引用悬垂
}
```

## 返回值优化（RVO / NRVO）

编译器会优化掉返回值的拷贝构造，直接在调用者的内存中构造对象：

```cpp
std::vector<int> make_vec() {
    std::vector<int> v = {1, 2, 3};
    return v;  // NRVO：不会拷贝，直接构造在调用方
}
```

C++17 保证了 RVO（纯右值的拷贝省略），即使拷贝构造函数被 `delete` 也合法。

## 多返回值

```cpp
// C++11：pair / tuple
std::pair<int, std::string> func();

// C++17：结构化绑定
auto [code, msg] = func();

// 输出参数（旧风格，不推荐）
void func(int& out1, std::string& out2);
```
