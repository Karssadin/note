# Go unsafe

`unsafe` 包允许绕过 Go 类型系统进行底层内存操作，适合少量性能敏感或系统边界场景。

## 常见能力

1. `unsafe.Pointer`：任意指针类型的中转。
2. `unsafe.Sizeof`：查看类型大小。
3. `unsafe.Alignof`：查看对齐要求。
4. `unsafe.Offsetof`：查看结构体字段偏移。

## 风险

1. 破坏类型安全。
2. 可能依赖具体平台、编译器或运行时实现。
3. 容易引入悬挂指针、越界访问和 GC 不可见引用。

## 原则

普通业务代码尽量不用 `unsafe`；需要使用时应把范围封装得很小，并写清楚不变量。
