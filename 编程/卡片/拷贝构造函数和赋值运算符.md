# 拷贝构造函数和赋值运算符

拷贝构造函数用于用已有对象初始化新对象，拷贝赋值运算符用于把已有对象的状态赋给另一个已存在对象。

```cpp
class A {
public:
    A(const A& other);            // 拷贝构造
    A& operator=(const A& other); // 拷贝赋值
};
```

## 区别

1. 拷贝构造发生在对象创建时。
2. 拷贝赋值发生在两个已存在对象之间。
3. 拷贝赋值需要处理自赋值。
4. 管理资源的类需要考虑三/五法则。

## 与移动语义

C++11 后，资源管理类通常同时定义移动构造和移动赋值，以减少深拷贝开销。详见 [[移动语义]]。
