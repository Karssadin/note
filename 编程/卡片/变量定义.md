### **给指定的内存空间取名，决定变量所占内存空间的大小和内存布局、该空间存储值范围**

语法：`type variable_list;`

- type必须是C++的数据类型，或者是自己定义的
- variable_list有一个或者多个由`,`分隔的名字

```C
int    i, j, k;
char   c, ch;
float  f, salary;
double d;
```

变量定义时初始化：`type variable_name = value;`

```C
extern int d = 3, f = 5;    // declaration of d and f.
int d = 3, f = 5;           // definition and initializing d and f.
byte z = 22;                // definition and initializes z.
char x = 'x';               // the variable x has the value 'x'.
```

不进行初始化的定义：具有静态存储持续时间的变量会被隐式初始化为NULL，其他所有变量的初始化值是未定义的
