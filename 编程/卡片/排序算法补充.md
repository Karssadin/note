[[sort：对序列进行排序]] 之外的排序相关算法，均在 `<algorithm>` 中，要求随机访问迭代器。

## stable_sort

稳定排序，相等元素保持原有相对顺序。时间 O(n log²n)，若有额外内存可达 O(n log n)。

```cpp
stable_sort(v.begin(), v.end());
stable_sort(v.begin(), v.end(), [](auto& a, auto& b){ return a.score > b.score; });
```

适用场景：先按成绩排序，成绩相同时保持原来的名字顺序。

## partial_sort

只排前 k 个最小元素到 `[first, middle)`，其余不保证顺序。时间 O(n log k)。

```cpp
partial_sort(v.begin(), v.begin() + 5, v.end());  // 前 5 个有序
```

适用场景：Top-K 问题（只需要最小的 K 个）。

## nth_element

将第 n 小的元素放到正确位置，左边全部 <= 它，右边全部 >= 它。时间 O(n)。

```cpp
nth_element(v.begin(), v.begin() + k, v.end());
// v[k] 就是第 k+1 小的元素
```

适用场景：快速选择、求中位数。

## is_sorted / is_sorted_until

```cpp
bool sorted = is_sorted(v.begin(), v.end());
auto it = is_sorted_until(v.begin(), v.end());  // 返回第一个破坏有序性的位置
```
