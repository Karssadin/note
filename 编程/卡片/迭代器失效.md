迭代器失效是指容器在插入、删除、扩容等操作后，原有迭代器指向的内存位置不再有效，继续使用会导致未定义行为。

## 各容器失效规则

| 容器 | 插入时 | 删除时 |
|------|--------|--------|
| vector | 扩容时全部失效；未扩容时插入点及之后失效 | 删除点及之后的迭代器失效 |
| deque | 头尾插入可能导致全部失效；中间插入全部失效 | 头尾删除仅该元素失效；中间删除全部失效 |
| list | 不失效（链表节点独立） | 仅被删除节点的迭代器失效 |
| set / map | 不失效（红黑树节点独立） | 仅被删除节点的迭代器失效 |
| unordered_map/set | rehash 时全部失效；未 rehash 时不失效 | 仅被删除节点的迭代器失效 |

## 正确处理方式

```cpp
// 错误：删除后 it 已失效
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it == target) v.erase(it);  // UB
}

// 正确：使用 erase 的返回值
for (auto it = v.begin(); it != v.end(); ) {
    if (*it == target) it = v.erase(it);
    else ++it;
}
```

- 优先使用 `erase` 返回的新迭代器
- 对 vector/deque，插入后所有迭代器都应视为失效
- 对 unordered 容器，插入可能触发 rehash，导致全部失效
