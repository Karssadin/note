## 深度优先遍历（DFS）

### 递归实现

```cpp
void preorder(TreeNode* cur, vector<int>& res) {
    if (!cur) return;
    res.push_back(cur->val);     // 前序：根-左-右
    preorder(cur->left, res);
    preorder(cur->right, res);
}

void inorder(TreeNode* cur, vector<int>& res) {
    if (!cur) return;
    inorder(cur->left, res);
    res.push_back(cur->val);     // 中序：左-根-右
    inorder(cur->right, res);
}

void postorder(TreeNode* cur, vector<int>& res) {
    if (!cur) return;
    postorder(cur->left, res);
    postorder(cur->right, res);
    res.push_back(cur->val);     // 后序：左-右-根
}
```

### 统一迭代法（标记法）

通过在栈中插入 `nullptr` 标记来统一前/中/后序的迭代写法，只需调整入栈顺序：

```cpp
vector<int> traversal(TreeNode* root) {
    stack<TreeNode*> st;
    vector<int> res;
    if (root) st.push(root);
    while (!st.empty()) {
        TreeNode* node = st.top();
        if (node) {
            st.pop();
            // 后序：根-右-左（入栈顺序反转）
            // st.push(node); st.push(nullptr);
            if (node->right) st.push(node->right);
            // 中序：右-根-左
            // st.push(node); st.push(nullptr);
            if (node->left) st.push(node->left);
            // 前序：右-左-根
            st.push(node); st.push(nullptr);
        } else {
            st.pop();
            node = st.top(); st.pop();
            res.push_back(node->val);
        }
    }
    return res;
}
```

## 广度优先遍历（BFS / 层序遍历）

### 迭代实现

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    queue<TreeNode*> que;
    vector<vector<int>> res;
    if (root) que.push(root);
    while (!que.empty()) {
        int size = que.size();
        vector<int> level;
        for (int i = 0; i < size; i++) {
            TreeNode* node = que.front(); que.pop();
            level.push_back(node->val);
            if (node->left) que.push(node->left);
            if (node->right) que.push(node->right);
        }
        res.push_back(level);
    }
    return res;
}
```

### 递归实现

```cpp
void dfs(TreeNode* cur, vector<vector<int>>& res, int depth) {
    if (!cur) return;
    if (res.size() == depth) res.push_back({});
    res[depth].push_back(cur->val);
    dfs(cur->left, res, depth + 1);
    dfs(cur->right, res, depth + 1);
}
```

## 遍历对比

| 遍历方式 | 数据结构 | 特点 | 典型应用 |
|----------|----------|------|----------|
| 前序 | 栈/递归 | 根优先 | 序列化、复制树 |
| 中序 | 栈/递归 | BST 有序输出 | BST 验证、第 K 大 |
| 后序 | 栈/递归 | 子树优先 | 计算高度、删除树 |
| 层序 | 队列 | 逐层处理 | 最短路径、宽度计算 |

## 面试要点

- 前序 + 中序可唯一确定一棵二叉树，后序 + 中序同理，但前序 + 后序不行
- Morris 遍历：O(1) 空间的中序遍历，利用叶节点的空指针作为线索
