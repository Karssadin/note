- **分治思想**
- 快速排序是一种基于分治的排序算法，它通过不断地将数组分成两个部分，分别对两个部分进行排序，最终得到一个有序的数组。
- 快速排序的基本步骤如下：
- 确定分界点：[l,r]，q[l],q[(l+r)/2]，q[r]，随机
- **调整区间，小于等于边界值的在左边，大于等于边界值的在右边**
- **用两个指针，i位于l，j位于r；移动i，如果q[i]小于边界值，不动，大于边界值的话去移动j；移动j，同理，碰到小于边界值的话，i和j指向的值可以进行一个交换，**`**i、j**`**向中间移动一位；继续循环i、j，直到**`**i≥j**`
    - **i指向第一个≥边界值的位置，j指向第一个≤边界值的**  
        在分区完成后，  
        `j` 是左半部分的最后一个元素，`j + 1` 是右半部分的第一个元素。  
          
          
        **位置**
- 递归处理左右两边

---

- 递归中如果划分中间值取`i-1、i`的话，递归的mid不能取`q[l]`，会出现边界问题。会一直死循环。
    - 同理，中间`j、j+1`的话，边界值不能取`q[r]`
- 碰到取第`K`个值的题，可以判断可以让递归进行判断中间值，进行一半的递归即可
- 取`mid=(r-l)/2+l`最后划分的结果是`[l,j]<=x [j+1]>=x`，取中间值为`j,j+1`

```C++
int N;
vec.resize(N);

void quickSort(vector<int> & v, int l, int r){
    if(l >= r)
        return;
    int mid_idx =(r - l >> 1) + l;
    int mid = v[mid_idx];
    int i = l - 1, j = r + 1;
    while(i < j){
        do{
            ++i;
        }while(v[i] < mid);
        do{
            --j;
        }while(v[j] > mid);
        if(i < j)
            swap(v[i], v[j]);
    }
    quickSort(v, l, j);
    quickSort(v, j + 1, r);
    
}
```
