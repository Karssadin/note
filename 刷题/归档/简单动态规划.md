- [509. 斐波那契数](https://leetcode.cn/problems/fibonacci-number/)
- 状态表示：
- dp[i]表示i的斐波那契数值
- 状态转移：
- `dp[i] = dp[i - 1] + dp[i - 2];`
- 状态初始化：`dp[0] = 0; dp[1] = 1;`
- 只用维护两个数字就行，不用声明一个A[N + 1]

```C
if (N <= 1) return N;
int dp[2];
dp[0] = 0;
dp[1] = 1;
for (int i = 2; i <= N; i++) {
    int sum = dp[0] + dp[1];
    dp[0] = dp[1];
    dp[1] = sum;
}
return dp[1];
```

- [70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs)
- 状态表示：dp[i]表示到i有多少种爬法
- 状态转移：`dp[i] = dp[i - 1] + dp[i - 2];`
- 状态初始化： `dp[0] = 1; dp[1] = 1;`
- 优化就使用两个元素的数组，更新

```C
if(n <= 1)
    return n;
vector<int> dp(n + 1);
dp[0] = 1;
dp[1] = 1;
for(int i = 2; i <= n; i++)
    dp[i] = dp[i - 1] + dp[i - 2];
return dp[n];
```

- [746. 使用最小花费爬楼梯](https://leetcode.cn/problems/min-cost-climbing-stairs)
- 状态表示：dp[i]表示到i的最低花费
- 状态转移：`dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2]);`
- 状态初始化：`dp[0] = 0; dp[1] = 0;`

```C
vector<int> dp(cost.size() + 1);
dp[0] = 0; // 默认第一步都是不花费体力的
dp[1] = 0;
//最后一步，cost.size();
for (int i = 2; i <= cost.size(); i++)
    dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2]);
return dp[cost.size()];
```

- [376. 摆动序列](https://leetcode.cn/problems/wiggle-subsequence/)
- 状态表示：
- 设 dp 状态dp[i][0]，表示考虑前 i 个数，第 i 个数作为山峰的摆动子序列的最长长度
- 设 dp 状态dp[i][1]，表示考虑前 i 个数，第 i 个数作为山谷的摆动子序列的最长长度
- 状态转移：
- dp[i][0] = max(dp[i][0], dp[j][1] + 1)，其中0 < j < i且nums[j] < nums[i]，表示将 nums[i]接到前面某个山谷后面，作为山峰。
- dp[i][1] = max(dp[i][1], dp[j][0] + 1)，其中0 < j < i且nums[j] > nums[i]，表示将 nums[i]接到前面某个山峰后面，作为山谷。
- 状态初始化：
- 由于一个数可以接到前面的某个数后面，也可以以自身为子序列的起点，所以初始状态为：dp[0][0] = dp[0][1] = 1

```C
int dp[1005][2];
int wiggleMaxLength(vector<int>& nums) {
    memset(dp, 0, sizeof dp);
    dp[0][0] = dp[0][1] = 1;
    for (int i = 1; i < nums.size(); ++i) {
        dp[i][0] = dp[i][1] = 1;
        for (int j = 0; j < i; ++j) {
            if (nums[j] > nums[i]) dp[i][1] = max(dp[i][1], dp[j][0] + 1);
        }
        for (int j = 0; j < i; ++j) {
            if (nums[j] < nums[i]) dp[i][0] = max(dp[i][0], dp[j][1] + 1);
        }
    }
    return max(dp[nums.size() - 1][0], dp[nums.size() - 1][1]);
}
```
