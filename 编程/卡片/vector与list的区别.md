| 维度 | vector | list |
|------|--------|------|
| 底层 | 连续数组 | 双向链表 |
| 随机访问 | O(1)，支持 `[]` | O(n)，不支持 `[]` |
| 插入删除 | 尾部 O(1)，中间 O(n)（需移动元素） | 任意位置 O(1)（只改指针） |
| 内存分配 | 一次分配连续空间，扩容时 2 倍（GCC）/1.5 倍（MSVC） | 每次插入单独申请一个节点 |
| 迭代器类型 | 随机访问迭代器 | 双向迭代器 |
| 迭代器失效 | 扩容时全部失效，删除时当前及之后失效 | 仅删除节点的迭代器失效 |
| 缓存友好 | 好（连续内存） | 差（节点分散） |
| 适用场景 | 随机访问多、尾部增删 | 频繁中间插入删除 |

- vector 的 `size()` 返回元素个数，`capacity()` 返回已分配空间
- `resize()` 改变 size（可能扩容），`reserve()` 只改变 capacity
- 收缩内存：`vector<int>(v).swap(v)`
- vector 元素不能是引用（引用无地址，无法连续存储）
