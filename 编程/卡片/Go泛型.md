# Go泛型

Go 1.18 引入泛型，通过类型参数和约束提升复用能力，但整体设计比 C++ 模板更克制。

```go
func Max[T constraints.Ordered](a, b T) T {
	if a > b {
		return a
	}
	return b
}
```

## 核心概念

1. 类型参数：`[T any]`
2. 约束：描述允许的类型集合和方法集合。
3. `any`：`interface{}` 的别名。
4. `comparable`：支持 `==` 和 `!=` 的类型约束。

## 使用原则

1. 当多个类型共享同一算法时使用泛型。
2. 不要为了少量重复代码过早引入类型参数。
3. 接口适合表达行为，泛型适合表达类型族上的算法。
