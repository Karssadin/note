-  **地址长度**：IPv4 的地址是 32 位的，但是 IPv6 的地址是 128 位的，
- **性能与特性**：除了更大的地址空间外，IPv6 还提供了增强的安全性、简化的头部结构和更好的路由和网络自动配置功能。
- **兼容性**：尽管 IPv6 在设计上是不与 IPv4 兼容的，但仍然有多种技术用于在两种协议之间进行过渡和转换。
- **自动配置**：IPv6 能够无需 DHCP 服务器的情况下自动配置网络接口。
- **简化的头部**：IPv6 的固定头部长度为 40 字节，这简化了首部结构并提高了路由器的转发效率。
- **没有 NAT**：由于其庞大的地址空间，IPv6 设计的初衷是不需要网络地址转换（NAT）。

- IPv6 地址的标识方法
    - **分组**：IPv6 地址长度是 128 位，是以每 16 位作为一组，每组用冒号 「:」 隔开。
    - **零压缩**：如果出现连续的 0 时还可以将这些 0 省略，并用两个冒号 「::」隔开。但是，一个 IP 地址中只允许出现一次两个连续的冒号。
- IPv6 地址的分类
    - 通过 IP 地址的前几位标识 IP 地址的种类。
    - 单播地址，用于一对一的通信
    - 组播地址，用于一对多的通信
    - 任播地址，用于通信最近的节点，最近的节点是由路由协议决定
    - 没有广播地址

- IPv6 单播地址类型
    - 链路本地地址：仅在同一链路上有效，不会被路由器转发。IPv4 没有此类型
    - 唯一本地地址：在整个本地网络中是唯一的，但不应在互联网上使用。相当于 IPv4 的私有 IP
    - 全局地址：可以在公网上使用，与 IPv4 的公共地址类似。
