- **原因**：每种数据链路的最大传输单元 MTU 都是不相同的，如 FDDI 数据链路 MTU 4352、以太网的 MTU 是 1500 字节等。最常见数据链路是以太网，它的 MTU 是 1500 字节。
- 当 IP 数据包大小大于 MTU 时， IP 数据包就会被分片。
- 经过分片之后的 IP 数据报在被重组的时候，只能由目标主机进行，路由器是不会进行重组的。
- 假设发送方发送一个 4000 字节的大数据报，若要传输在以太网链路，则需要把数据报分片成 3 个小数据报进行传输，再交由接收方重组成大数据报。
- TCP的MSS：在分片传输中，一旦某个分片丢失，则会造成整个 IP 数据报作废，所以 TCP 引入了 MSS 也就是在 TCP 层进行分片不由 IP 层分片。MSS的选择考虑了底层TCP的MTU，确保TCP的段不会被分片。对于 UDP 尽量不要发送一个大于 MTU 的数据报文
- **Path MTU Discovery**：这是一个用于动态发现路径上最小MTU的技术，从而避免分片。发送方首先假设一个大的MTU（如1500字节），并将数据包标记为“不可分片”。如果路由器发现数据包太大并且不能被传输，它会返回一个表示“需要进行分片但不允许分片”的ICMP错误消息。发送方接收到此消息后会调整其MTU并重试。
