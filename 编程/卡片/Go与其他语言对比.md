# Go与其他语言对比

Go 适合从并发模型、内存管理、类型系统、工程工具链和运行时角度与其他语言建立关联。

1. [[Go与C++对比]]
2. [[Go并发模型对比]]
3. [[Go接口与C++抽象类对比]]

## 对比维度

1. C++：更强调零成本抽象、RAII、模板和手动资源控制。
2. Java：同样有 GC 和成熟运行时，但并发单位通常是线程或虚拟线程。
3. Python：语法灵活、生态丰富，但 CPU 并行受 GIL 影响。
4. Go：内置 goroutine/channel，工具链统一，语言特性相对克制。
