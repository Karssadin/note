信号（Signal）是 Unix/Linux 系统中进程间通信的一种异步通知机制，用于通知进程某个事件已经发生。

## 常见信号

| 信号 | 编号 | 默认行为 | 说明 |
|------|------|---------|------|
| SIGINT | 2 | 终止 | Ctrl+C 发送 |
| SIGKILL | 9 | 终止（不可捕获） | 强制杀死进程 |
| SIGSEGV | 11 | 终止 + core | 段错误（非法内存访问） |
| SIGTERM | 15 | 终止 | `kill` 命令默认发送 |
| SIGCHLD | 17 | 忽略 | 子进程状态变化 |
| SIGSTOP | 19 | 暂停（不可捕获） | 暂停进程 |

## 信号处理

```cpp
#include <signal.h>

void handler(int signo) {
    // 信号处理函数，应尽量简短
    // 只能调用异步信号安全函数（不能用 printf、malloc）
}

signal(SIGINT, handler);     // 注册处理函数
signal(SIGINT, SIG_IGN);     // 忽略信号
signal(SIGINT, SIG_DFL);     // 恢复默认行为
```

## 发送信号

```cpp
kill(pid, SIGTERM);   // 向指定进程发送信号
raise(SIGINT);        // 向自身发送信号
alarm(5);             // 5秒后发送 SIGALRM
```

SIGKILL 和 SIGSTOP 不可被捕获或忽略。
