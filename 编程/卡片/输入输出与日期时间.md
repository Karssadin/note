## 标准输入输出

```cpp
#include <iostream>

std::cin >> x;              // 从标准输入读取，以空白符分隔
std::cout << "val=" << x;   // 输出到标准输出
std::cerr << "error";       // 输出到标准错误（无缓冲）
std::clog << "log";         // 输出到标准错误（有缓冲）

std::getline(std::cin, str);  // 读取整行（含空格）
```

## 格式化输出

```cpp
#include <iomanip>

std::cout << std::setw(10) << std::left << "name";        // 左对齐，宽度 10
std::cout << std::setprecision(3) << std::fixed << 3.14;   // 保留 3 位小数
std::cout << std::hex << 255;       // ff（十六进制）
std::cout << std::oct << 255;       // 377（八进制）
std::cout << std::boolalpha << true; // "true"
```

## 日期与时间

C 风格（`<ctime>`）：

```cpp
time_t now = time(nullptr);         // 当前时间戳（秒）
tm* local = localtime(&now);        // 转为本地时间结构体
char buf[64];
strftime(buf, sizeof(buf), "%Y-%m-%d %H:%M:%S", local);  // 格式化
```

C++11 `<chrono>`（推荐）：

```cpp
#include <chrono>

auto start = std::chrono::steady_clock::now();
// ... 执行代码 ...
auto end = std::chrono::steady_clock::now();
auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(end - start).count();
```

| 时钟 | 特点 |
|------|------|
| `system_clock` | 系统时间，可能被调整 |
| `steady_clock` | 单调递增，适合计时 |
| `high_resolution_clock` | 最高精度时钟 |
