### 单调栈

单调栈是一种常用的数据结构，它可以帮助我们在一个数组中快速地寻找某个元素左侧或右侧第一个比它大或比它小的元素。

单调栈的本质是空间换时间，因为在遍历的过程中需要用一个栈来记录右边第一个比当前元素高的元素，优点是只需要遍历一次。

给定一个长度为N的整数数列，输出每个数左边第一个比它小的数，如果不存在则输出−1

维护一个单调递增或单调递减的栈，对于一个新的元素，将栈中比它小（或大）的元素全部弹出，然后将它入栈。这样，栈顶元素就是该元素左侧（或右侧）第一个比它小（或大）的元素。

---

- 单调队列是一种常用的数据结构，它可以帮助我们在一个滑动窗口内快速地寻找最大值或最小值。
- 单调队列的思想是，维护一个单调递增或单调递减的队列，对于一个新的元素，将队列中所有比它小（或大）的元素全部弹出，然后将它入队。这样，队首元素就是该滑动窗口内的最大值（或最小值）。
- 有一个大小为k的滑动窗口，它从数组的最左边移动到最右边。你只能在窗口中看到k个数字。每次滑动窗口向右移动一个位置。确定滑动窗口位于每个位置时，窗口中的最大值和最小值。

- [剑指 Offer 59 - I. 滑动窗口的最大值](https://leetcode.cn/problems/hua-dong-chuang-kou-de-zui-da-zhi-lcof)

```C
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> q;
    vector<int> res;
    for (int i = 0; i < nums.size(); i++) {
        //如果front的位置超过窗口，就pop
        if (!q.empty() && q.front() == i - k)
            q.pop_front();
        //如果尾部的比当前值小，就pop，因为不可能输出这个值
        while (!q.empty() && nums[q.back()] < nums[i])
            q.pop_back();
        //将当前值放入
        q.push_back(i);
        if (i >= k - 1)
            res.push_back(nums[q.front()]);
    }
    return res;
}

vector<int> minSlidingWindow(vector<int>& nums, int k) {
    deque<int> q;
    vector<int> res;
    for (int i = 0; i < nums.size(); i++) {
        if (!q.empty() && q.front() == i - k)
            q.pop_front();
        while (!q.empty() && nums[q.back()] > nums[i])
            q.pop_back();
        q.push_back(i);
        if (i >= k - 1)
            res.push_back(nums[q.front()]);
    }
    return res;
}
```
