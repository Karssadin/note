# Go数组和切片

数组是定长值类型，切片是对底层数组的动态视图。实际开发中更常用切片。

## 数组

```go
var a [3]int
```

1. 长度是类型的一部分，`[3]int` 和 `[4]int` 是不同类型。
2. 数组赋值会拷贝整个数组。

## 切片

```go
s := []int{1, 2, 3}
s = append(s, 4)
```

1. 切片包含指针、长度和容量。
2. `append` 可能触发扩容并迁移到底层新数组。
3. 多个切片可能共享同一个底层数组，修改时需要注意别名影响。
4. 大切片截取小切片可能导致底层大数组无法释放。
