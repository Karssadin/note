## 核心思想

在搜索空间中通过**试探 + 撤销**逐步构建解。本质是带**剪枝**的 DFS。

## 通用框架

```cpp
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        收集结果;
        return;
    }
    for (选择 : 选择列表) {
        做选择;          // 修改路径
        backtrack(路径, 选择列表);
        撤销选择;        // 恢复现场
    }
}
```

## 经典问题分类

| 类型 | 问题 | 关键点 |
|------|------|--------|
| 排列 | 全排列 | `used[]` 标记已选元素 |
| 组合 | 组合总和 | `startIndex` 避免重复选取 |
| 子集 | 子集枚举 | 每个元素选或不选 |
| 棋盘 | N 皇后、解数独 | 行/列/对角线约束 |
| 分割 | 分割回文串 | 枚举切割位置 |
| 图搜索 | 单词搜索 | 四方向扩展 + 访问标记 |

## 剪枝技巧

剪枝是回溯效率的关键，常见策略：

1. **可行性剪枝**：当前选择已不可能满足约束，立即返回
2. **排序剪枝**：对候选元素排序，当元素超过目标时终止循环
3. **对称性剪枝**：利用问题的对称性减少搜索
4. **重复剪枝**：排序后跳过相同元素 `if (i > start && nums[i] == nums[i-1]) continue`

## 组合示例

```cpp
vector<vector<int>> result;
vector<int> path;

void backtrack(vector<int>& candidates, int target, int start) {
    if (target == 0) {
        result.push_back(path);
        return;
    }
    for (int i = start; i < candidates.size(); i++) {
        if (candidates[i] > target) break;  // 排序剪枝
        path.push_back(candidates[i]);
        backtrack(candidates, target - candidates[i], i);
        path.pop_back();
    }
}
```

## 回溯 vs 动态规划

| 维度 | 回溯 | 动态规划 |
|------|------|----------|
| 目标 | 枚举所有解 / 找一个可行解 | 求最优值 |
| 搜索方式 | DFS + 剪枝 | 状态转移 |
| 时间复杂度 | 指数级（最坏） | 多项式级（通常） |
| 适用 | 排列/组合/子集/约束满足 | 最优化问题 |
