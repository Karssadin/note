MySQL 支持插件式存储引擎架构，常用引擎对比如下：

| 特性 | InnoDB | MyISAM | Memory |
|------|--------|--------|--------|
| 事务 | 支持 | 不支持 | 不支持 |
| 锁粒度 | 行级锁 | 表级锁 | 表级锁 |
| 外键 | 支持 | 不支持 | 不支持 |
| 崩溃恢复 | 支持（redo log） | 不支持 | 数据易丢失 |
| MVCC | 支持 | 不支持 | 不支持 |
| 全文索引 | 支持（5.6+） | 支持 | 不支持 |
| 存储方式 | 聚簇索引 | 堆表 + 非聚簇索引 | 内存哈希/B树 |
| 适用场景 | OLTP、高并发 | 只读/读多写少 | 临时表、缓存 |

## 选择建议

- **默认选 InnoDB**：需要事务、并发控制、崩溃恢复的场景
- **MyISAM**：历史遗留系统，或纯只读的全文检索场景
- **Memory**：临时计算结果，会话级缓存（重启后数据丢失）

## 查看与设置

```sql
SHOW ENGINES;                          -- 查看可用引擎
SHOW TABLE STATUS LIKE 'table_name';   -- 查看表使用的引擎
ALTER TABLE t ENGINE = InnoDB;         -- 修改表引擎
```
