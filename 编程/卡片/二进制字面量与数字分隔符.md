C++14 新增两个提升代码可读性的字面量特性。

## 二进制字面量

用 `0b` 或 `0B` 前缀表示二进制数值：

```cpp
int mask  = 0b1111'0000;  // 240
int flags = 0b0010'0100;  // 36

// 位操作更直观
if (value & 0b0000'0001) { /* 最低位为 1 */ }
```

之前只能用十六进制 `0xF0` 或十进制 `240`，不够直观。

## 数字分隔符

用单引号 `'` 作为分隔符，不影响数值，仅提升可读性：

```cpp
int million     = 1'000'000;
double pi       = 3.14159'26535'89793;
long hex_color  = 0xFF'AA'00;
int binary      = 0b0001'0010'0011'0100;
long long big   = 100'000'000'000LL;
```

分隔符可以放在任意数字之间，但不能放在前缀（`0x`、`0b`）之后或数字开头/结尾。
