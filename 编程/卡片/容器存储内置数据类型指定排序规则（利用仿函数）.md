- 默认情况下，STL容器中的排序是从小到大的。可以通过定义一个仿函数来改变默认排序规则。在插入元素之前需要设置规则

```C++
\#include <iostream>
\#include <set>

// 重载()，形成仿函数
class MyCompare {
public:
    bool operator()(int v1, int v2) const {
        return v1 > v2;  // 定义从大到小的排序规则
    }
};

int main() {
    // 使用仿函数指定排序规则
    std::set<int, MyCompare> s2;
    s2.insert(10);
    s2.insert(20);
    s2.insert(5);

    for (const auto& elem : s2) {
        std::cout << elem << " ";
    }
    // 输出: 20 10 5
    return 0;
}
```
