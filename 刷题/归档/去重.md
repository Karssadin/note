- 全排列去重
- [47. 全排列 II](https://leetcode.cn/problems/permutations-ii/)

```C
for(int i = 0; i < nums.size(); i++){
    if(i > 0 && nums[i] == nums[i - 1] && !used[i - 1] )
        continue;
    // 初始遍历，遍历的时候置为true，标记当前path这个值已经使用过了
    // 遍历之后置为false，代表当前层这个值已经使用过了
    // 剪枝的时候    判断true而且相等的话就不用进行path填充， 避免有重复的值
    // 同层剪枝
    // 如果是同路径剪枝的话，要走很多重复路径，
    if(!used[i]){
        used[i] = true;
        path.push_back(nums[i]);
        backtracking(nums, used);
        path.pop_back();
        used[i] = false;
    }
}
```
