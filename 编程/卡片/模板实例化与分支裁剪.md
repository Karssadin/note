- 模板函数 / 类模板在使用时会被 **实例化（instantiate）**，生成具体类型版本。
- 编译器在实例化时需要对 **整个函数体或类模板的语句合法性**进行检查。
- 目的是保证模板对给定类型是安全的，即使某些分支永远不会执行。
```C++
struct A {};
struct B { void foo(){}; };

template<typename T>
void f(T t) {
    if (sizeof(T) == 8)
        t.foo(); // 对 A 报错
}

int main() {
    f(A{}); // ❌ 编译错误
    f(B{}); // ✅ OK
}
```
- 虽然 `sizeof(A) != 8`，运行时不会执行 t.foo()
- 编译器实例化模板时仍会检查整个函数体，编译报错报错

> 如果是C17的话，可以使用if constexpr来进行条件参见，防止编译错误分支
