- 在互联网或局域网中，每台计算机或设备都有一个唯一的 IP 地址，用于标识其在网络上的位置。路由器使用 IP 地址确定如何将数据从源地址传输到目标地址。
- 在局域网内，计算机使用 MAC 地址进行设备间的通信。
- IP 地址可以跨网络工作，用于长距离通信，而 MAC 地址通常仅在局域网内使用。
- IP 地址在网络层使用，而 MAC 地址在数据链路层使用。
- IP 地址可以更改（例如，当您从一个网络移动到另一个网络时），但 MAC 地址通常是固定的。
- ARP（地址解析协议）用于将 IP 地址映射到 MAC 地址，从而在局域网内进行通信。
