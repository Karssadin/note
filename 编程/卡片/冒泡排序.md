# 冒泡排序

冒泡排序每轮比较相邻元素，把当前未排序区间中的最大值逐步交换到末尾。

```cpp
for (int i = 0; i < n - 1; ++i) {
    bool swapped = false;
    for (int j = 0; j < n - 1 - i; ++j) {
        if (a[j] > a[j + 1]) {
            swap(a[j], a[j + 1]);
            swapped = true;
        }
    }
    if (!swapped) break;
}
```

## 特点

1. 平均和最坏时间复杂度为 O(n²)。
2. 最好情况下可通过提前结束优化到 O(n)。
3. 空间复杂度为 O(1)。
4. 稳定排序，适合教学和小规模基本有序数据。
