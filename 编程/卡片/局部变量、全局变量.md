在`function和block`中声明的变量叫Local变量，只能在`function和block`使用

- Global变量在所有函数外面定义，通常在程序最上面，可以被任何函数访问

```C
\#include <iostream>
using namespace std;

// Global variable declaration:
int g;

int main () {
   // Local variable declaration:
   int a, b;

   // actual initialization
   a = 10;
   b = 20;
   g = a + b;

   cout << g;

   return 0;
}
```

- 当函数的全局变量和局部变量重名时，程序使用的是局部变量
