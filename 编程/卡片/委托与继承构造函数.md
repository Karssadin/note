C++11 引入委托构造函数和继承构造函数，减少构造函数中的重复代码。

## 委托构造函数

一个构造函数可以调用同类的另一个构造函数：

```cpp
class Widget {
    int x, y;
    std::string name;
public:
    // 主构造函数
    Widget(int x, int y, std::string name)
        : x(x), y(y), name(std::move(name)) {}

    // 委托给主构造函数
    Widget() : Widget(0, 0, "default") {}
    Widget(int x) : Widget(x, 0, "unnamed") {}
};
```

C++98 中只能通过 init() 私有方法提取公共逻辑，委托构造更安全（保证完整初始化）。

## 注意事项

- 委托和成员初始化列表不能同时使用：`Widget() : Widget(0), x(1) {}` 非法
- 避免循环委托：A 委托 B，B 委托 A 会导致未定义行为

## 继承构造函数

使用 `using` 将基类构造函数引入派生类：

```cpp
class Base {
public:
    Base(int x) {}
    Base(int x, int y) {}
    Base(std::string s) {}
};

class Derived : public Base {
public:
    using Base::Base;  // 继承 Base 的所有构造函数
    // 等价于自动生成：
    // Derived(int x) : Base(x) {}
    // Derived(int x, int y) : Base(x, y) {}
    // Derived(std::string s) : Base(s) {}
};

Derived d1(42);       // OK
Derived d2(1, 2);     // OK
Derived d3("hello");  // OK
```

## 继承构造的限制

- 如果派生类有新增成员，继承的构造函数不会初始化这些成员（使用类内默认值）
- 多继承时如果两个基类有相同签名的构造函数，会产生歧义，需要手动定义
