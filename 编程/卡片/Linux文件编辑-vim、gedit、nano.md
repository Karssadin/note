## Vim

Linux 标准编辑器，三种模式切换：

| 模式 | 进入方式 | 作用 |
|------|---------|------|
| 普通模式 | 启动默认 / `Esc` | 移动光标、删除、复制粘贴 |
| 插入模式 | `i`（当前位置）/ `a`（后一位）/ `o`（新行） | 输入文本 |
| 命令模式 | `:` | 保存退出、搜索替换、设置 |

### 常用操作

| 操作 | 命令 |
|------|------|
| 保存退出 | `:wq` 或 `ZZ` |
| 不保存退出 | `:q!` |
| 删除一行 | `dd` |
| 复制一行 | `yy`，粘贴 `p` |
| 撤销 | `u`，重做 `Ctrl+r` |
| 搜索 | `/keyword`，`n` 下一个 |
| 替换 | `:%s/old/new/g` |
| 跳到行首/行尾 | `0` / `$` |
| 跳到文件首/尾 | `gg` / `G` |
| 显示行号 | `:set nu` |

## nano

轻量级编辑器，适合快速编辑。底部显示快捷键提示（`^` 表示 Ctrl）。

- `nano file` 打开文件
- `Ctrl+O` 保存，`Ctrl+X` 退出
- `Ctrl+K` 剪切行，`Ctrl+U` 粘贴
- `Ctrl+W` 搜索

## gedit

GNOME 桌面环境的图形化文本编辑器，`gedit file` 打开。适合有 GUI 环境时使用，不适合远程 SSH。
