## starrocks
- docker配置release版本
```
docker search starrocks

docker run -p 9030:9030 -p 8030:8030 -p 8040:8040 -itd --name sr starrocks/allin1-ubuntu

docker exec -it sr mysql -P 9030 -h 127.0.0.1 -u root --prompt="StarRocks > "

docker start sr
sudo apt-get install mysql-client-core-8.0

mysql -P9030 -h127.0.0.1 -uroot --prompt="StarRocks > "
```

## duckdb
- duckdb编译debug版本

```
git clone https://github.com/duckdb/duckdb.git
cd duckdb
mkdir build && cd build && cmake -GNinja -DCMAKE_BUILD_TYPE=debug -DCMAKE_EXPORT_COMPILE_COMMANDS=ON .. && ninja -j4
#如果-j后面数字太大，可能会编译失败，根据配置来
```
