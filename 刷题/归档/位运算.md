### 位运算+有限状态机

- [剑指 Offer 56 - II. 数组中数字出现的次数 II](https://leetcode.cn/problems/shu-zu-zhong-shu-zi-chu-xian-de-ci-shu-ii-lcof)
- 这个要求找没有出现三次只出现一次的数字，相同位数上有很多位是出现多次的，但是很多都是3的倍数，要找的是余1次数的位。所以当某位出现三次1之后，要将其归0
- 需要使用两位二进制来进行状态统计：00 01 10，输入位是0，状态保持不变，输入1跳转至下一个状态
- 为什么不使用一个个的判断呢？上面的介绍只是针对一位来说的，但是int有32位，所以需要进行批量处理

```C
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ones = 0, twos = 0;
        for(int num : nums){
            ones = ones ^ num & ~twos;
            twos = twos ^ num & ~ones;
        }
        return ones;
    }
};
```

### lowbit操作

- `N`的二进制表示第`K`位数字是多少（`n>>k&1`）：
- 先右移`>>K`位,把第`k`位放到最后一位
- 看个位是几，`&1`即可
- `lowbit`算法是一种用于求出二进制数最低位为1的位数，它主要用于树状数组算法中：
- `lowbit(x)`是返回`X`最后一位1
- x=1010 返回 10
- x=101000 返回 1000
- `lowbit`实现：`x&(-x)`
- 原理：
- 一个数字原码是10001000，他的负数表示形式是补码，就是反码+1，反码是01110111
- `x=~x+1`
- 取反将最后一位1和后面的0变成01111，+1之后变成10000.相与之后只有1的位置为1，所以输出该数字

---

- 一个数组中有两个数字出现次数为奇数个
- 如果一个数组全部^起来之后结果不为0。数组中可以分成两类，就是对应异或结果1位是否为0..可以做一个数组中有两个数字出现次数为奇数个

例子：给定一个长度为n的数列，请你求出数列中每个数的二进制表示中1的个数。

- `n>>k&1`操作

```C
\#include <iostream>
using namespace std;
const int  N = 100010;

int A[N];
int main(){
    int n;
    ios::sync_with_stdio(false);
    cin>>n;
    for(int i=0;i<n;i++)
        cin>>A[i];

    for(int i=0;i<n;i++){
        int res=0;
        while(A[i]){
            //&1之后为0说明该位是0，反之位1
           res+=A[i]&1;
           A[i]>>=1;
        }
        cout<<res<<" ";
    }
    return 0;
}
```

- `lowbit`操作

```C
\#include <iostream>
using namespace std;
const int  N = 100010;

int A[N];
int lowbit(int x){
    return x & -x;
}
int main(){
    int n;
    ios::sync_with_stdio(false);
    cin>>n;
    for(int i=0;i<n;i++)
        cin>>A[i];

    for(int i=0;i<n;i++){
        int res=0;
        while(A[i]){
            A[i] -= lowbit(A[i]);
            res++;
        }
        cout<<res<<" ";
    }
    return 0;
}
```
