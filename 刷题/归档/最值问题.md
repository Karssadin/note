### 股票问题

- [122. 买卖股票的最佳时机 II](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii)
- 收集每天的正利润

```C
int maxProfit(vector<int>& prices) {
    int res = 0;
    for(int i = 1; i < prices.size(); i++)
        res += max(prices[i] - prices[i - 1], 0);

    return res;
}
```
