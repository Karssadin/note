# 模板

- 模板是 C++ 语言中的一个特性，允许你编写通用的、与类型无关的代码。这些代码在编译时根据所提供的具体类型或值进行实例化。

```C
template <typename T>
T max(T a, T b) {
    return (a > b) ? a : b;
}
```

- 异步任务（`**std::async**`）
- `**std::future**` 和 `**std::promise**`

- std::async是一种更简单的并行执行方式，它返回一个std::future，你可以用它来获取async任务的结果。

```C
int myFunction(int x) { return x*2; }
auto future = std::async(myFunction, 10);
int result = future.get();  // 获取结果，如果线程未完成则会阻塞
```
