C++14 允许普通函数省略尾置返回类型，编译器从 `return` 语句自动推导。

## C++11 的限制

C++11 需要尾置返回类型 `-> decltype(...)` 才能让编译器推导：

```cpp
// C++11
auto add(int a, int b) -> decltype(a + b) { return a + b; }
```

## C++14 改进

```cpp
// C++14：直接省略，编译器推导
auto add(int a, int b) { return a + b; }

// 多个 return 必须推导出相同类型
auto func(bool flag) {
    if (flag) return 1;    // int
    else return 2;         // int，OK
    // return 1.0;         // 错误：与 int 冲突
}
```

## 注意事项

- 递归函数必须先有一个非递归的 return 语句，编译器才能推导
- 不能用于虚函数
- 头文件中声明的函数如果使用 `auto` 返回类型，定义必须可见
