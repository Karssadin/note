创建型模式。将复杂对象的**构建**与其**表示**分离，使同样的构建过程可以创建不同的表示。适用于有多个可选参数或构建步骤的对象。

## 解决了什么问题

构造函数参数过多（Telescoping Constructor），导致可读性差、易出错：

```cpp
// 问题：参数多且顺序难记
Pizza p("large", "thick", "cheese", "tomato", true, false, true);
```

## 代码示例

```cpp
class Pizza {
    string size, crust, sauce;
    bool cheese = false, pepperoni = false;

    Pizza() {}  // 私有构造

public:
    class Builder {
        Pizza pizza;
    public:
        Builder& setSize(const string& s)   { pizza.size = s;      return *this; }
        Builder& setCrust(const string& c)  { pizza.crust = c;     return *this; }
        Builder& setSauce(const string& s)  { pizza.sauce = s;     return *this; }
        Builder& addCheese()    { pizza.cheese = true;    return *this; }
        Builder& addPepperoni() { pizza.pepperoni = true; return *this; }
        Pizza build() { return pizza; }
    };
};

// 使用（链式调用）
Pizza p = Pizza::Builder()
    .setSize("large")
    .setCrust("thick")
    .setSauce("tomato")
    .addCheese()
    .build();
```

## 与工厂模式的区别

| 维度 | 建造者 | 工厂方法 |
|------|--------|----------|
| 关注点 | 复杂对象的分步构建 | 对象的创建（哪种类型） |
| 产品 | 通常是同一个类，配置不同 | 通常是不同类的产品 |
| 步骤 | 多步骤，顺序可控 | 通常一步完成 |

## 应用案例

- `std::ostringstream`：逐步拼接字符串
- SQL 查询构建器：`SELECT ... FROM ... WHERE ... ORDER BY ...`
- GUI 组件构建：可选设置宽高、颜色、字体等
