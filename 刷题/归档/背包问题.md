### 01背包问题

现有N件物品和一个最多能承重M的背包，第i件物品的重量是v[i]，价值是w[i].在背包能承受的范围内，试问将哪些物品装入背包后可使总价值最大，求这个最大价值。

---

- 状态表示
- f[i][j]:表示所有选法集合中,只从前i个物品中选,并且总体积≤j的选法的集合,它的值是这个集合中每一个选法的最大值,则f[N][M]就是本题的答案
- 状态转移
- f[i][j] = max(f[i-1][j], f[i-1][j-v[i]]+w[i])
- f[i-1][j]:不选第i个物品的集合中的最大值
- f[i-1][j-v[i]]+w[i]:选第i个物品的集合,但是直接求不容易求所在集合的属性,这里迂回打击一下,先将第i个物品的体积减去,求剩下集合中选法的最大值.
- f数组的初始化：当背包承重为0时，显然装不下任何物品，所以 f[i][o]=0。若一个物品也不选（即从前0个物品中选），此时最大价值也是0，所以f[0][j]= 0。由此可知f数组应当全0初始化，即声明为全局变量

```C
\#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N];
int f[N][N];
int n,m;
int main() {
    cin >> n >> m;
    for(int i = 1; i <= n; i++) cin >> v[i] >> w[i];
    for(int i = 1; i <= n; i++) {
        for(int j = 0; j <= m; j++) {
            //不放i的最大值
            f[i][j] = f[i-1][j];
            //放i的最大值
            if(j>=v[i]) f[i][j] = max(f[i][j], f[i-1][j-v[i]]+w[i]);
        }
    }

    cout << f[n][m] << endl;
 return 0;
}
```

---

- 使用滚动数组优化，f数组在上面为二维数组，这里更新第i层用i-1层更新，不如直接在当前行更新。只需要使用一行来存储，就是一维数组
- 但如果j从小到大遍历，状态转移方程就变成了f[i][j] = max(f[i-1][j], f[i][j-v[i]]+w[i]),会导致，在更新f[j-w[i]]之后才使用f[j-w[i]]，也就是使用了当前i层的结果来更新i层的结果

```C
//有优化版
/*
1. f[i] 仅用到了f[i-1]层,
2. j与j-v[i] 均小于j
3.若用到上一层的状态时,从大到小枚举, 反之从小到大哦
*/
\#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N];
int f[N];
int n,m;
int main() {
    cin >> n >> m;
    for(int i = 1; i <= n; i++) cin >> v[i] >> w[i];
    for(int i = 1; i <= n; i++) {
        for(int j = m; j>=v[i]; j--) {
            //f[j-v[i]+w[i]为放i的话，最大值是多少
            //计算的是，背包从0-m容量，能装多少
            f[j] = max(f[j], f[j-v[i]]+w[i]);
        }
    }

    cout << f[m] << endl;
 return 0;
}
```

### 完全背包问题

有 N 件物品和一个容量是 V 的背包。每件物品个数没有限制第 i 件物品的体积是 vi，价值是 wi。求解将哪些物品装入背包，可使这些物品的总体积不超过背包容量，且总价值最大。输出最大价值

---

- 状态表示
- f[i][j]:表示所有选法集合中,只从前i个物品中选,并且总体积≤j的选法的集合,它的值是这个集合中每一个选法的最大值.
- 状态转移：第i个物品选多少个
- f[i][j] = max(f[i-1][j], f[i-1][j-k_v[i]]+k_w[i])
- f[i-1][j]:不选第i个物品的集合中的最大值
- f[i-1][j-k_v[i]]+k_w[i]:选第i个物品的集合,但是直接求不容易求所在集合的属性,这里迂回打击一下,先将第i个物品的体积减去,求剩下集合中选法的最大值.

---

```C
\#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N];
int f[N][N];
int n,m;
int main() {
    cin >> n >> m;
    for(int i = 1; i <= n; i++) cin >> v[i] >> w[i];
    for(int i = 1; i <= n; i++)
        for(int j = 0; j <= m; j++)
            for(int k=0;k*v[i]<=j;k++)
                    f[i][j] = max(f[i][j], f[i-1][j-k*v[i]]+k*w[i]);


    cout << f[n][m] << endl;
 return 0;
}
```

---

- 展开之后会发现
- f[i][j]
- f[i][j] = max(f[i-1][j], f[i][j-v[i]]+w[i])
- 该式对应的是 j从小到大遍历，于是我们只需把01背包问题的代码中的 j改为从小到大遍历即可

```C
\#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N];
int f[N];
int n,m;
int main() {
    cin >> n >> m;
    for(int i = 1; i <= n; i++) cin >> v[i] >> w[i];
    for(int i = 1; i <= n; i++)
        for(int j = v[i]; j <= m; j++)
            f[j] = max(f[j], f[j-v[i]]+w[i]);


    cout << f[m] << endl;
 return 0;
}
```

### 多重背包问题

有 N 件物品和一个容量是 V 的背包。每件物品的个数为Si  第 i 件物品的体积是 vi，价值是 wi。 求解将哪些物品装入背包，可使这些物品的总体积不超过背包容量，且总价值最大。输出最大价值

- 回顾完全背包问题的暴力解法，在背包承重为j的前提下，第i种物品最多能放t=j/w[i]个（这里是整除）。而在01背包问题中，第 i种物品只有一个，所以应当取t=min(1,j/w[i])。由此可见，对于多重背包问题，只需取t=min(s[i],j/w[i])

---

```C
\#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int v[N],w[N],s[N];
int f[N][N];
int n,m;
int main() {
    cin >> n >> m;
    for(int i = 1; i <= n; i++) cin >> v[i] >> w[i]>>s[i];
    for(int i = 1; i <= n; i++)
        for(int j = 0; j <= m; j++){
            int t=min(s[i],j/v[i]);
            for(int k=0;k<=t;k++)
                    f[i][j] = max(f[i][j], f[i-1][j-k*v[i]]+k*w[i]);
        }
    cout << f[n][m] << endl;
 return 0;
}
```

---

- 对于每个物品，从0~s[i]一直遍历，要遍历s[i]次
- 将s[i]个物品分散至log2 s[i]+1个箱子中，拆分成很多个箱子，这些箱子每个只选一次，就成了01背包问题

### 分组背包问题

物品有N组，每组里面有若干个物品，每组中只能选一个物品。输出最大价值

---

- f[i][j] = max(f[i-1][j], max (k: 1-s[i]) f[i][j-v[i]s[k]]+w[i][s[k]])
- 优化成一维: f[j] = max(f[j], f[j - v[i][k]] + w[i][k])

---

```C
\#include <bits/stdc++.h>
using namespace std;

const int N = 110;
int w[N][N], v[N][N], s[N];
int f[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> s[i];
        for (int j = 1; j <= s[i]; j++)
            cin >> v[i][j] >> w[i][j];
    }

    for (int i = 1; i <= n; i++)
        for (int j = m; j >= 1; j--)
            for (int k = 1; k <= s[i]; k++)
                if (j >= v[i][k])
                    f[j] = max(f[j], f[j - v[i][k]] + w[i][k]);

    cout << f[m] << "\n";

    return 0;
}
```
