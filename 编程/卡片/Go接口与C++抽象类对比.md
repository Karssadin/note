# Go接口与C++抽象类对比

Go 接口和 C++ 抽象类都能表达多态，但实现方式和耦合程度不同。

| 维度 | Go接口 | C++抽象类 |
|------|--------|-----------|
| 实现方式 | 隐式实现 | 显式继承 |
| 关系声明 | 使用方定义接口即可 | 类型层次通常提前设计 |
| 多态成本 | 接口值动态分派 | 虚函数表动态分派 |
| 数据字段 | 接口不包含字段 | 抽象类可以包含字段 |
| 组合方式 | 小接口组合 | 继承和组合都可用 |

## 理解重点

1. Go 鼓励在消费方定义小接口。
2. C++ 抽象类更适合表达稳定的类型层级。
3. Go 接口的 nil 问题来自接口值包含动态类型和动态值。
