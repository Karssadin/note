结构型模式。动态地给对象**增加额外职责**，比继承更灵活。装饰器和被装饰对象实现同一接口，可层层包装。

## 解决了什么问题

继承扩展功能会导致类爆炸（如咖啡 × 加奶 × 加糖 × 加冰 = 多种组合）。装饰器通过**组合**代替继承，运行时动态组合。

- **稳定点**：核心对象接口
- **变化点**：附加功能的种类和组合方式

## 代码示例（咖啡店）

```cpp
class Beverage {
public:
    virtual string getDescription() = 0;
    virtual double cost() = 0;
    virtual ~Beverage() {}
};

// 基础饮料
class Espresso : public Beverage {
    string getDescription() override { return "Espresso"; }
    double cost() override { return 1.99; }
};

// 装饰器基类
class CondimentDecorator : public Beverage {
protected:
    Beverage* beverage;
public:
    CondimentDecorator(Beverage* b) : beverage(b) {}
};

// 具体装饰器
class Milk : public CondimentDecorator {
public:
    Milk(Beverage* b) : CondimentDecorator(b) {}
    string getDescription() override {
        return beverage->getDescription() + ", Milk";
    }
    double cost() override { return beverage->cost() + 0.25; }
};

class Mocha : public CondimentDecorator {
public:
    Mocha(Beverage* b) : CondimentDecorator(b) {}
    string getDescription() override {
        return beverage->getDescription() + ", Mocha";
    }
    double cost() override { return beverage->cost() + 0.20; }
};

// 使用
Beverage* b = new Espresso();
b = new Milk(b);
b = new Mocha(b);  // 层层包装
cout << b->getDescription() << " $" << b->cost();
// 输出：Espresso, Milk, Mocha $2.44
```

## 应用案例

- **C++ I/O 流**：`ifstream` → `BufferedReader` → `LineReader`
- **中间件**：HTTP 请求通过日志→鉴权→限流中间件链
- **Java**：`InputStream` → `BufferedInputStream` → `DataInputStream`
