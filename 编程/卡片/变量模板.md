C++14 引入变量模板（Variable Templates），允许用 `template` 定义参数化的变量。

## 基本语法

```cpp
template <typename T>
constexpr T pi = T(3.14159265358979323846);

double area = pi<double> * r * r;
float  x    = pi<float> * 2;
```

## 之前的替代方案

C++11 中需要用函数模板或类模板静态成员模拟：

```cpp
// C++11 函数模板方式
template <typename T>
constexpr T pi() { return T(3.14159265); }

// C++11 类模板方式
template <typename T>
struct pi_holder { static constexpr T value = T(3.14159265); };
```

## 标准库中的应用

C++17 标准库大量使用变量模板简化 type traits：

```cpp
// C++11/14 写法
std::is_integral<int>::value   // bool

// C++17 变量模板版本
std::is_integral_v<int>        // bool，更简洁
```

`_v` 后缀的变量模板定义方式：

```cpp
template <typename T>
inline constexpr bool is_integral_v = std::is_integral<T>::value;
```
