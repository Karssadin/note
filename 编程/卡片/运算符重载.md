> **对已有的运算符赋予另一种功能，适应不同的数据类型（而不是让其只适用于内置数据类型）**

- 有两种方法：
    - 通过成员函数重载
    - 通过全局函数重载：**不能使用this**
- 运算符重载函数也可以使用友元
- 运算符重载也可以发生函数重载，类似函数重载
- 重载运算符函数，本质还是函数调用，所以重载后：
    - `data1+data2`
    - `operator+(data1, data)`
- 重载运算符如果是类的成员函数，左侧运算对象就相当于固定了是this

### 加法运算符 + 重载

```C++
//通过成员函数重载+号
Person operator+ (Person& p){
	Person temp;
	temp.m_a=this->m_a+p.m_a;
	return temp;
}
Person p3=p1.operator+(p2);
//简写
Person p3=p1+p2

//通过全局函数重载
Person operator+ (Person & p1 ,Person & p2){
	Person temp;
	temp.m_a=p1.m_a+p2.m_a;
	return temp;
}
Person p3=operator+(p1,p2);
//简写
Person p3=p1+p2;
```

### 左移运算符 << 重载

> **输出自定义数据类型**

- 需要返回 ostream类型，方便链式调用

```C++
//如果使用ostream & operator<<(ostream &cout),调用时候使用p.operator<<(cout)，简化版本为p<<cout,不对，因此不用成员函数来重载左移运算符，用全局函数来重载 ，成员函数需要使用对象来调用<<，所以对象在<<左边


//使用全局函数来重载<<，operator<<(cout,p),简化为cout<<p
ostream &operator<<(ostream &cout,Person &p){
	return cout
};
```

### 重载前置与后置++

```C++
Myint & operator++(){//前置
    this->num++;
    return *this;
}
MyInterger operator++(int){//后置
    MyInterger temp = *this;
    m_Num++;
    return temp;
}
```

- 为了区分前后置，重载函数是以参数类型来区分，在调用的时候，编译器默默给int指定为一个0
- 前置返回引用是为了多次++时候对同一个对象进行++，而不是单独的数据
- 后置
    - 重载后置++运算符,int 代表占位参数，可以用于区分前置和后置递增，
    - 而temp是一个局部对象，函数实现完成后，系统会自动清空数据
    - 若返回局部临时对象的引用再去访问改地址就属于非法操作
    - 添加const是为了防止连续调用两次++，因为这种重载无法实现两次++，需要禁止两次++ 的出现

---

- 关于递增和递减运算符的重载中前置和后置：
    - 占位符是cpp特色,用来区分两个函数，就可以用重载
    - 所以cpp标准规定“不常用的”后置++是有占位符的
    - “常用的”前置++是没有占位符的,因为前置是常用的，所以才选择让他没有占位符，方便，前置不创建临时对象，不带来构造和析构而造成的格外开销
    - ++p是正确用法，p++不建议使用

### 赋值运算符 = 重载

- 如果对象中有在堆上的属性，如果使用编译器提供的简单 = 浅拷贝赋值运算符，在析构时候可能会出现重复释放的问题。

```C
Person & operatot=(Person &p){
	if(age!=NULL)
		delete age;
	this->age=new int(*p.age);

	return *this;
}
```

### 关系运算符 == 重载

```C
int operator==(Person &p){
	if(this->age==p.age)
		return 1;
	else
		return 0;
}
```

### 函数调用运算符()重载——仿函数

- 使用起来类似函数调用，叫`仿函数`
- 没有特殊的写法，非常灵活，在stl课中很多这个

```C
void operator()(){
	cout<<age<<endl;
}
Person p;
p();
Person()();//匿名对象调用
```
