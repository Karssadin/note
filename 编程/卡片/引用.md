- 给变量取别名，别名指向内存的相同区域，地址相同
- 跟踪状态、传递参数、性能提升
- 引用必须初始化，初始化之后不可更改
- 引用的本质：指针常量int * const——指向不可变，指向地址的内容可以变
- 引用在内部存放的是一个对象的地址，它是该对象的别名。对于不可寻址的值，如文字常量，以及不同类型的对象，编译器为了实现引用，必须生成一个临时对象，引用实际上指向该对象，但用户不能访问它

```C++
\#include <iostream>

void add_three(int &a) { a = a + 3; }

int main() {

  int a = 10;
  int &b = a;

  // 10.
  std::cout << "b is " << b << std::endl;

  add_three(a);
  std::cout << "a is " << a << std::endl;

  return 0;
}
```
