## 最小生成树（MST）

**定义**：在一个连通无向加权图中，找到一棵包含所有顶点、边权之和最小的**生成树**（Minimum Spanning Tree）。

**性质**：
- 有 V 个顶点，则 MST 有 V-1 条边
- MST 不唯一（当存在相同权重的边时）
- 切割定理：对于图的任意一个切割，连接两侧的最小权边一定在某棵 MST 中

## Kruskal 算法

**思想**：贪心——按边权从小到大排序，依次添加不构成环的边。

**数据结构**：并查集（Union-Find）检测是否成环

```cpp
struct Edge { int u, v, w; };

class UnionFind {
    vector<int> parent, rank;
public:
    UnionFind(int n) : parent(n), rank(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }
    bool unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false;  // 已在同一连通分量
        if (rank[px] < rank[py]) swap(px, py);
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
        return true;
    }
};

int kruskal(int n, vector<Edge>& edges) {
    sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) {
        return a.w < b.w;
    });
    UnionFind uf(n);
    int total = 0, cnt = 0;
    for (auto& e : edges) {
        if (uf.unite(e.u, e.v)) {
            total += e.w;
            if (++cnt == n - 1) break;
        }
    }
    return cnt == n - 1 ? total : -1;  // -1 表示图不连通
}
```

- **时间复杂度**：O(E log E)（排序主导）
- **适用**：稀疏图（边少）

## Prim 算法

**思想**：从一个顶点出发，每次将离当前 MST 最近的顶点加入树中。

**类似 Dijkstra**，使用小顶堆维护候选边。

```cpp
int prim(int n, vector<vector<pair<int,int>>>& adj) {
    // adj[u] = {v, weight}
    vector<int> key(n, INT_MAX);  // key[v] = 连接 v 到当前MST的最小边权
    vector<bool> inMST(n, false);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;

    key[0] = 0;
    pq.push({0, 0});
    int total = 0;

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (inMST[u]) continue;
        inMST[u] = true;
        total += d;

        for (auto [v, w] : adj[u]) {
            if (!inMST[v] && w < key[v]) {
                key[v] = w;
                pq.push({w, v});
            }
        }
    }
    return total;
}
```

- **时间复杂度**：O((V+E)logV)（使用优先队列）
- **适用**：稠密图（边多）

---

## Kruskal vs Prim 对比

| 维度 | Kruskal | Prim |
|------|---------|------|
| 核心思想 | 按边贪心 + 并查集 | 按顶点贪心 + 优先队列 |
| 时间复杂度 | O(E log E) | O((V+E)log V) |
| 适合图类型 | 稀疏图 | 稠密图 |
| 实现复杂度 | 中（需要并查集）| 中（类 Dijkstra）|
| 处理不连通图 | 得到森林 | 无法处理（从单点出发）|

## 拓扑排序（Topological Sort）

**定义**：对有向无环图（DAG）的所有顶点进行线性排序，使得每条有向边 u→v，u 在排序中出现在 v 之前。

**应用**：任务调度、依赖解析（npm 包依赖）、课程选修顺序

### Kahn 算法（BFS 版本）

```cpp
vector<int> topoSort(int n, vector<vector<int>>& adj) {
    vector<int> indegree(n, 0);
    for (int u = 0; u < n; u++)
        for (int v : adj[u]) indegree[v]++;

    queue<int> q;
    for (int i = 0; i < n; i++)
        if (indegree[i] == 0) q.push(i);

    vector<int> order;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : adj[u])
            if (--indegree[v] == 0) q.push(v);
    }

    if (order.size() != n) return {};  // 有环
    return order;
}
```

- 时间复杂度：O(V+E)
- 若结果中节点数 < V，说明图中存在环（即不是 DAG）
