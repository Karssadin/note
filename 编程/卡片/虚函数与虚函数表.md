## 虚函数

**定义**：在基类中用 `virtual` 关键字声明，在派生类中可以被重写（override）的成员函数。

**目的**：实现运行时多态（动态绑定）——通过基类指针/引用调用派生类的实现。

```cpp
class Animal {
public:
    virtual void speak() { std::cout << "..." << std::endl; }
    virtual ~Animal() {}  // 析构函数应为虚函数
};

class Dog : public Animal {
public:
    void speak() override { std::cout << "Woof!" << std::endl; }
};

Animal* a = new Dog();
a->speak();  // 输出 "Woof!"（动态绑定）
```

## 虚函数的限制

- **必须是非静态成员函数**：静态函数在编译期确定，无法动态绑定
- **构造函数不能是虚函数**：对象未创建完成，虚表指针未初始化
- **析构函数应该是虚函数**：防止基类指针删除派生类对象时只调用基类析构
- **可以是内联函数**（形式上），但虚函数通过虚表调用时不会内联

## 虚函数表（vtable）

每个包含虚函数的类有一个 **虚函数表（vtable）**，每个对象有一个指向该表的 **虚表指针（vptr）**。

```
Dog 对象内存布局：
┌──────────────────┐
│ vptr ────────────┼──→ Dog::vtable
│  data members... │        ├── Dog::speak
└──────────────────┘        └── Animal::~Animal (或 Dog::~Dog)
```

**动态绑定的过程：**
1. 通过对象的 vptr 找到 vtable
2. 在 vtable 中按偏移量找到对应虚函数的地址
3. 调用该函数

**性能开销：**
- 每个对象增加一个 vptr（通常 8 字节，64位系统）
- 虚函数调用需额外一次间接寻址（相比直接调用慢一点，但通常可忽略）
- 无法内联，可能影响编译器优化

## 关键字

- `virtual`：声明虚函数（派生类重写时可省略，但建议保留）
- `override`：显式声明重写，让编译器验证签名一致性（C++11）
- `final`：禁止进一步重写或禁止类被继承（C++11）

## 纯虚函数与抽象类

```cpp
class Shape {
public:
    virtual double area() const = 0;  // 纯虚函数：= 0
    virtual ~Shape() {}
};
// Shape 是抽象类，不能实例化，派生类必须实现 area()
```
