- localhost 就不叫 IP，它是一个域名，就跟 "baidu.com",是一个形式的东西，用于表示本地机器上的网络接口。当你在计算机上使用localhost时，它实际上指向一个IP地址，即IPv4的回环地址127.0.0.1或IPv6的回环地址::1。使用localhost时，你可以通过网络接口访问本地计算机上运行的网络服务，而不需要通过网络连接。
- 127.0.0.1（IPv4回环地址）：127.0.0.1是IPv4的回环地址，也被称为本地回环地址。它是保留的IP地址范围，用于在本地计算机上进行网络通信。当你将网络请求发送到127.0.0.1时，它会被路由到本地计算机上的网络接口，实现与本机的通信。
- 0.0.0.0：0.0.0.0是一个特殊的IP地址，通常用作通配符地址或监听所有可用网络接口的地址。当服务器绑定到0.0.0.0时，它将监听所有可用的网络接口，能够接收来自任意IP地址的请求。这对于服务器需要在多个网络接口上监听的情况非常有用。
