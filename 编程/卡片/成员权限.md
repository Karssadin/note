- 将属性和行为作为一个整体、将属性和行为加一些**权限控制**
- 权限分为三种：
    - `public`：公共权限。类内(类内的行为和属性)可以访问，类外可以访问
    - `protected`：保护权限。类内可以访问，类外不可以访问
    - `private`：私有权限。 类内可以访问，类外不可以访问
- 子类可以访问父类中的`protect`、`public`，不可以访问父类的`private`
- 可以将属性的权限设置为`private`，使用`public`函数来调用属性的相应行为`set`、`get`，需要`set`、`get`就设置，不需要就不设置，可以在相应函数做各种判断
- 类中行为函数的参数可以为类的对象，例如：判断两个对象是否相等

```C
//class 类名{ 访问权限：属性/行为};
class Circle{
public://访问权限，公共权限
	//属性
	int m_r://半径

    //行为
    //获取原的周长
    double calcZC(){
    	return 2*PI*m_r;
    }
};
int main(){
	Circle c1;
	c1.m_r=10;
	cout<<c1.calcZC()<<endl;
}
```
