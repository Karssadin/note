**内存池（Memory Pool）**：预先申请一大块内存，程序从池中按需分配和回收，避免频繁调用系统 `malloc/free`。

## 核心原理

```
┌───────────────────────────────────────┐
│  预分配的大内存块（从 OS 申请一次）      │
│ ┌──────┬──────┬──────┬──────┬──────┐  │
│ │ 已用  │ 空闲 │ 已用  │ 空闲 │ 空闲 │  │
│ └──────┴──────┴──────┴──────┴──────┘  │
│                 内存池管理的 free list  │
└───────────────────────────────────────┘
```

**三个阶段**：
1. **初始化**：预分配固定大小内存，建立空闲链表
2. **分配**：从 free list 取出一块（O(1)），无需系统调用
3. **回收**：将内存块归还 free list（O(1)），不立即释放给 OS

## 定长内存池实现（C++）

```cpp
template<typename T, size_t POOL_SIZE = 1024>
class FixedMemoryPool {
    union Block {
        T data;
        Block* next;   // 空闲时作为链表指针
    };

    Block pool[POOL_SIZE];
    Block* free_head = nullptr;

public:
    FixedMemoryPool() {
        // 初始化空闲链表
        for (size_t i = 0; i < POOL_SIZE - 1; ++i)
            pool[i].next = &pool[i + 1];
        pool[POOL_SIZE - 1].next = nullptr;
        free_head = &pool[0];
    }

    T* alloc() {
        if (!free_head) return nullptr;   // 池满
        Block* block = free_head;
        free_head = free_head->next;
        return &block->data;
    }

    void dealloc(T* ptr) {
        Block* block = reinterpret_cast<Block*>(ptr);
        block->next = free_head;
        free_head = block;
    }
};

// 使用示例
FixedMemoryPool<MyObject> pool;
MyObject* obj = pool.alloc();
new (obj) MyObject(args...);  // placement new
obj->~MyObject();             // 手动析构
pool.dealloc(obj);
```

## 变长内存池（按大小分级）

工业级实现（jemalloc/tcmalloc）使用按大小分级策略：

```
小对象（≤256B）：用固定大小的 slab，减少碎片
中对象（256B~4KB）：用多种规格 slab 分级
大对象（>4KB）：直接 mmap/malloc
```

## 优点

| 优点 | 说明 |
|------|------|
| **高速分配** | O(1) 分配/释放，无系统调用 |
| **减少碎片** | 定长块无外部碎片 |
| **减少 OS 交互** | 批量申请，减少 `brk()`/`mmap()` 调用次数 |
| **局部性好** | 同类型对象紧凑存放，Cache 友好 |

## 内存池的实际应用

| 项目 | 内存池实现 |
|------|-----------|
| **tcmalloc**（Google） | 线程本地缓存 + 中央 heap，减少锁竞争 |
| **jemalloc**（Firefox/Redis） | Arena 机制 + 大小分级，减少碎片 |
| **nginx** | `ngx_pool_t`：请求级内存池，请求结束后统一释放 |
| **Linux Slab** | 内核对象缓存，对 `task_struct` 等频繁分配的结构使用 |

## 与 STL allocator 的关系

STL 容器可自定义 allocator，实现内存池分配：

```cpp
// C++17 多态分配器
#include <memory_resource>

std::array<std::byte, 1024> buffer;
std::pmr::monotonic_buffer_resource pool{buffer.data(), buffer.size()};
std::pmr::vector<int> v{&pool};  // 从栈上的缓冲区分配
```

## 使用场景

- **高频创建销毁**小对象（如网络请求处理中的 buffer）
- **实时系统**（避免 malloc 的不确定延迟）
- **游戏引擎**中的粒子系统、子弹等大量同类对象
- **数据库连接池**（本质也是资源池思想）
