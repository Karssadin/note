`<algorithm>` 中的二分查找系列，**要求序列已排序**，时间 O(log n)。

## lower_bound

返回第一个 **>=** 目标值的迭代器（插入位置）。

```cpp
vector<int> v = {1, 3, 5, 7, 9};
auto it = lower_bound(v.begin(), v.end(), 5);  // 指向 5
auto it2 = lower_bound(v.begin(), v.end(), 4); // 指向 5（第一个 >= 4 的）
int idx = it - v.begin();  // 下标
```

## upper_bound

返回第一个 **>** 目标值的迭代器。

```cpp
auto it = upper_bound(v.begin(), v.end(), 5);  // 指向 7
```

## equal_range

返回 `pair<lower_bound, upper_bound>`，即等于目标值的区间 `[lb, ub)`。

```cpp
auto [lb, ub] = equal_range(v.begin(), v.end(), 5);
int count = ub - lb;  // 等于 5 的元素个数
```

## 常见用法

```cpp
// 判断是否存在（比 binary_search 更灵活，能拿到位置）
auto it = lower_bound(v.begin(), v.end(), target);
if (it != v.end() && *it == target) { /* 找到 */ }

// 在有序数组中插入并保持有序
auto pos = lower_bound(v.begin(), v.end(), newVal);
v.insert(pos, newVal);

// 自定义比较器
lower_bound(v.begin(), v.end(), target, [](const auto& a, int b){ return a.key < b; });
```
