模板特化（Specialization）允许为特定类型提供不同于通用模板的实现。

## 全特化（Full Specialization）

为所有模板参数指定具体类型：

```cpp
// 通用版本
template <typename T>
struct Hash {
    size_t operator()(const T& val) const {
        return static_cast<size_t>(val);
    }
};

// 全特化：为 std::string 提供特殊实现
template <>
struct Hash<std::string> {
    size_t operator()(const std::string& s) const {
        size_t hash = 0;
        for (char c : s) hash = hash * 31 + c;
        return hash;
    }
};
```

函数模板也可以全特化，但通常**优先用重载**而非特化（重载参与更直观的重载决议）。

## 偏特化（Partial Specialization）

只对部分模板参数特化，或对参数施加约束。**函数模板不支持偏特化**，只有类模板可以。

```cpp
// 通用版本
template <typename T, typename U>
struct Pair {
    T first; U second;
};

// 偏特化：两个类型相同时
template <typename T>
struct Pair<T, T> {
    T first, second;
    bool equal() const { return first == second; }
};

// 偏特化：第二个参数为指针时
template <typename T, typename U>
struct Pair<T, U*> {
    T first; U* second;
    void deref() { /* 可以解引用 second */ }
};
```

## 常见应用

1. **标准库 type_traits**：`is_pointer<T>` 通用版返回 false，`is_pointer<T*>` 偏特化返回 true
2. **std::vector<bool>**：对 `bool` 全特化以压缩存储（每个 bool 仅占 1 bit）
3. **自定义容器/算法**：为特定类型提供优化实现

## 与 if constexpr 的关系

C++17 的 `if constexpr` 可以在一个模板函数内部按条件分支，减少对函数模板全特化的需求：

```cpp
template <typename T>
void process(T val) {
    if constexpr (std::is_pointer_v<T>)
        std::cout << *val;
    else
        std::cout << val;
}
```
