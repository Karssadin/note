利用**大顶堆**的性质实现排序：堆顶始终是最大值，每次将堆顶与末尾交换，缩小堆的范围并重新调整。

- 时间复杂度：O(n log n)，建堆 O(n) + n 次调整 O(log n)
- 空间复杂度：O(1)，原地排序
- **不稳定**

## 核心操作

### 下沉调整（Heapify）

```cpp
void heapify(vector<int>& arr, int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && arr[left] > arr[largest])
        largest = left;
    if (right < n && arr[right] > arr[largest])
        largest = right;

    if (largest != i) {
        swap(arr[i], arr[largest]);
        heapify(arr, n, largest);
    }
}
```

### 堆排序

```cpp
void heapSort(vector<int>& arr) {
    int n = arr.size();

    // 建堆：从最后一个非叶节点开始下沉
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(arr, n, i);

    // 逐个提取堆顶
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]);
        heapify(arr, i, 0);
    }
}
```

## 与快排/归并的比较

| 维度 | 堆排序 | 快排 | 归并 |
|------|--------|------|------|
| 最坏复杂度 | O(n log n) | O(n²) | O(n log n) |
| 额外空间 | O(1) | O(log n) | O(n) |
| 缓存友好性 | 差（跳跃访问） | 好（顺序访问） | 中 |
| 稳定性 | 不稳定 | 不稳定 | 稳定 |

堆排序的最坏复杂度有保证，但因缓存命中率低，实际性能通常不如快排。适合对**最坏复杂度敏感且内存受限**的场景。
