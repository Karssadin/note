重复遍历数组，比较相邻元素，将较大的元素"冒泡"到右端。

- 时间复杂度：平均/最坏 O(n²)，最好 O(n)（已有序 + `swapped` 优化）
- 空间复杂度：O(1)
- **稳定排序**

```cpp
void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break; // 本轮无交换说明已有序
    }
}
```

`swapped` 标志是关键优化：如果某轮遍历没有发生交换，说明数组已有序，提前终止。
