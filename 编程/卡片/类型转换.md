- 隐式类型转换（promotion & usual arithmetic conversions）
    
    - 整型提升（integer promotion）
        
    - 浮点/整型算术转换规则
        
- 显式类型转换（C 风格）
    
    - `(T)x` / `T(x)` 的区别与危险
        
- C++ 四种显式转换运算符（推荐使用）
    
    - `static_cast<T>(expr)`：常规转换（算术，指针到void*，基类/派生间非虚转换等）
        
    - `reinterpret_cast<T>(expr)`：位解释层面转换（危险，平台相关）
        
    - `const_cast<T>(expr)`：去/加 const/volatile（仅用于修饰符）
        
    - `dynamic_cast<T>(expr)`：带 RTTI 的安全向下转型（多态类型）
        
- 用户定义的转换
    
    - 转换构造函数 `A::A(const B&)`（从 B 到 A）
        
    - 转换运算符 `operator T()`（从类到 T）
        
    - explicit 构造函数与 explicit operator（避免隐式转换）
        
    - 歧义与意外转换的防护（explicit / delete）
        
- 引用/指针转换规则（包括多继承时的指针偏移）
    
- 数值范围与截断（窄化转换，注意 UB 与实现定义行为）
    
- 模板与类型转换
    
    - 模板推导时的类型转换影响（完美转发/decay）
        
    - SFINAE/enable_if 控制可转换性
        
- 推荐实践与常见坑
    
    - 优先用 `static_cast`（非位级）或 `dynamic_cast` 做明确意图表达
        
    - 避免 C 风格强转与 `reinterpret_cast`（除非非常必要）
        
    - 使用 `explicit` 防止意外隐式转换
