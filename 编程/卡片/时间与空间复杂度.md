## 时间复杂度

衡量算法运行时间随输入规模增长的变化趋势，使用大 O 表示法（Big-O）描述**最坏情况**下的上界。

### 常见复杂度

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| O(1) | 常数 | 数组按下标访问、哈希表查找 |
| O(log n) | 对数 | 二分查找、平衡 BST 操作 |
| O(n) | 线性 | 遍历数组、链表 |
| O(n log n) | 线性对数 | 归并排序、快速排序（平均） |
| O(n²) | 平方 | 冒泡排序、选择排序、暴力枚举 |
| O(2ⁿ) | 指数 | 子集枚举、递归斐波那契（无记忆化） |
| O(n!) | 阶乘 | 全排列枚举 |

### 分析方法

- **循环法**：嵌套循环层数决定多项式阶数
- **递归法**：主定理（Master Theorem）`T(n) = aT(n/b) + O(nᵈ)`
  - `d < log_b(a)` → O(n^log_b(a))
  - `d = log_b(a)` → O(nᵈ log n)
  - `d > log_b(a)` → O(nᵈ)
- **均摊分析**：`vector` 扩容，单次 O(n) 但均摊 O(1)

## 空间复杂度

衡量算法额外使用的内存空间随输入规模的增长趋势。

| 复杂度 | 示例 |
|--------|------|
| O(1) | 原地排序（冒泡、插入） |
| O(log n) | 递归二分查找（栈深度） |
| O(n) | 归并排序辅助数组、哈希表 |
| O(n²) | 二维 DP 表 |

### 时空权衡

空间换时间是算法优化的核心手段：

- **哈希表**：O(n) 空间将查找从 O(n) 降为 O(1)
- **记忆化搜索**：O(n) 空间将指数复杂度降为多项式
- **前缀和**：O(n) 预处理实现 O(1) 区间查询

## 面试要点

1. 分析复杂度时只关注**最高阶项**，忽略常数系数和低阶项
2. 最好/最坏/平均复杂度的区别（如快排最坏 O(n²)，平均 O(n log n)）
3. 递归算法的空间复杂度需计入**调用栈深度**
4. `O(n log n)` 是基于比较的排序算法的理论下界
