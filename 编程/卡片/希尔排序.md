插入排序的改进版。核心思想：先让间隔较远的元素基本有序，逐步缩小间隔，最终进行一次普通插入排序。

- 时间复杂度：取决于增量序列，通常 O(n^1.3)~O(n^1.5)
- 空间复杂度：O(1)
- **不稳定**：跨间隔交换可能破坏相等元素顺序

## 实现

```cpp
void shellSort(vector<int>& arr) {
    int n = arr.size();
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int key = arr[i];
            int j = i;
            while (j >= gap && arr[j - gap] > key) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            arr[j] = key;
        }
    }
}
```

## 增量序列

| 序列 | 最坏复杂度 |
|------|-----------|
| Shell 序列 n/2, n/4, ..., 1 | O(n²) |
| Hibbard 序列 1, 3, 7, 15, ... | O(n^1.5) |
| Knuth 序列 1, 4, 13, 40, ... | O(n^1.5) |
| Sedgewick 序列 | O(n^(4/3)) |

希尔排序在中等规模数据上性能优异，且实现简单、空间开销小，适合嵌入式系统。
