枚举（Enum）是一种将整数值命名为符号常量的数据类型，提高代码可读性。

## C 风格 enum

```cpp
enum Color { RED, GREEN, BLUE };  // 默认值：0, 1, 2
Color c = GREEN;  // c == 1

enum Direction { NORTH = 1, SOUTH, EAST = 10, WEST };
// NORTH=1, SOUTH=2, EAST=10, WEST=11
```

## C++11 enum class（强类型枚举）

```cpp
enum class Color { Red, Green, Blue };
enum class Direction { North, South };

Color c = Color::Red;        // 必须加作用域前缀
// int x = Color::Red;       // 错误：不能隐式转换为 int
int x = static_cast<int>(Color::Red);  // 需要显式转换

// 不同枚举值不会冲突
Color c2 = Color::Green;
Direction d = Direction::North;  // 不同于 Color，不会产生歧义
```

## enum vs enum class

| 特性 | `enum` | `enum class` |
|------|--------|-------------|
| 作用域 | 全局污染（`RED` 即可用） | 需限定（`Color::Red`） |
| 隐式整数转换 | 可以（`int x = RED;`） | 不可以，需 `static_cast` |
| 不同枚举名冲突 | 可能冲突 | 不会冲突 |
| 底层类型指定 | C++11 后支持 | 支持（默认 int） |

## 指定底层类型

```cpp
enum class Status : uint8_t {
    OK = 0,
    Error = 1,
    Timeout = 2
};
// sizeof(Status) == 1
```

## 枚举与 switch

```cpp
switch (c) {
    case Color::Red:   /* ... */ break;
    case Color::Green: /* ... */ break;
    case Color::Blue:  /* ... */ break;
}
// 若有漏掉的枚举值，编译器（-Wall）会警告
```

## 实践建议

- 优先使用 `enum class` 避免命名污染
- 为枚举指定底层类型（便于序列化、节省内存）
- 对外暴露状态码时使用枚举，而非魔法数字
