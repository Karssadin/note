# 快速排序

快速排序通过选择基准值 pivot，把数组划分为小于 pivot 和大于 pivot 的两部分，再递归排序子区间。

```cpp
void quickSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int i = l, j = r, pivot = a[l + (r - l) / 2];
    while (i <= j) {
        while (a[i] < pivot) ++i;
        while (a[j] > pivot) --j;
        if (i <= j) swap(a[i++], a[j--]);
    }
    quickSort(a, l, j);
    quickSort(a, i, r);
}
```

## 特点

1. 平均时间复杂度为 O(n log n)。
2. 最坏时间复杂度为 O(n²)，通常用随机 pivot 或三数取中缓解。
3. 递归栈平均 O(log n)，最坏 O(n)。
4. 不稳定排序。
5. 实践中缓存友好，常作为通用排序基础。
